# 数据库 · 领域总览

> **一句话**：数据如何持久化、并发地被查询与修改。

## 这个领域回答的问题

- 一条 SQL 在引擎里怎么执行？
- 索引为什么能让查询快两个数量级？
- 两个事务同时改同一行会发生什么？

## 边界：它不负责什么

不深入某个商业数据库的运维参数调优；不替代数据分析/数仓建模。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 30 数据结构与算法（B+ 树、哈希）、50 操作系统（页、缓冲） |
| **学完之后支撑** | 110 后端开发、140 分布式系统、150 系统架构 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
