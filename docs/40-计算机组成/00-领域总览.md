# 计算机组成 · 领域总览

> **一句话**：一行代码在机器层面到底发生了什么。

## 这个领域回答的问题

- 数据在寄存器里长什么样？
- 函数调用如何压栈？
- 为什么这段循环快十倍？

## 边界：它不负责什么

不深入芯片物理与工艺；不替代体系结构研究（见 160）。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 20 编程基础、二进制与基本的逻辑门直觉 |
| **学完之后支撑** | 50 操作系统、80 编译原理、120 软件安全 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
