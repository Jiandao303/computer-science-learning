# DevOps与运维 · 领域总览

> **一句话**：代码如何稳定、可重复地到达生产环境。

## 这个领域回答的问题

- 如何做到一次构建、处处运行？
- 上线出问题时如何三分钟内回滚？
- 系统慢了，从哪一层开始查？

## 边界：它不负责什么

不做云厂商认证题库；不替代安全合规。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 50 操作系统（Linux）、60 计算机网络、110 后端开发 |
| **学完之后支撑** | 150 系统架构 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
