# 操作系统 · 领域总览

> **一句话**：多个程序如何安全、公平地共享同一台机器。

## 这个领域回答的问题

- 进程切换时到底保存了什么？
- 两个线程为什么会互相卡死？
- 内存不够时系统做了什么？

## 边界：它不负责什么

不深入内核某个子系统的实现细节（驱动、文件系统专项）；不替代分布式系统。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 40 计算机组成 |
| **学完之后支撑** | 60 计算机网络、110 后端开发、140 分布式系统 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
