# C 语言学习总览

> **这不是一份完整的 C 语言教程。** 它的唯一目标：把生疏的 C 恢复到手能写、脑能推的程度，然后进 15-213。
> 凡是 15-213 不讲、你也不会用到的语言细节（例如 `_Complex`、`restrict` 的全部语义），本库不覆盖。

## 一句话总结

C 的难点从来不是语法，而是**「内存里到底发生了什么」**：指针存的是地址，数组会退化成指针，`malloc` 给你的是没有类型的一块字节，栈上的变量出了作用域就失效。10 个模块按「先能写 → 再能管内存 → 最后能调试」排列，8 天走完。

## 学习目标

学完本库，你应该能：

1. 不看资料写出带多文件、带 `Makefile`、带错误处理的 C 程序。
2. 画出一段 C 程序运行时的内存布局（栈 / 堆 / 数据段 / 代码段），并指出每个变量的位置。
3. 解释 `p + 1` 为什么不是「地址加 1」，`a[i]` 为什么等价于 `*(a + i)`。
4. 用 GDB 定位段错误，用 Valgrind 定位内存泄漏与越界。
5. 说明 C0 与标准 C 的差别，知道本库的代码一律是标准 C（`-std=c11`）。

## 术语与版本约定

- **标准 C**：本库所有代码按 ISO C11 写，编译参数固定 `-std=c11 -Wall -Wextra -Wpedantic`。
- **C0**：CMU 15-122 前九周用的教学语言（有契约 `//@requires`、`//@ensures`、`//@loop_invariant`）。**本库不使用 C0**，只在需要对照时提一句。
- **GNU C 扩展**：`__attribute__`、嵌套函数、语句表达式等。**本库不使用**，用到时明确标注。
- 术语译名见 [13-术语词典](13-术语词典.md)，全库统一。
