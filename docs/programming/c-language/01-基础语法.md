# 01 基础语法

> 对应模块 01。目标不是「认识语法」，而是**建立一套能预测程序行为的模型**：每个变量占几个字节、存在哪里、什么时候消失。

## 学习目标

1. 写出带 `main`、函数、循环、条件分支的完整 C 程序，并解释它的执行顺序。
2. 说清 `int` / `char` / `float` / `double` 的典型字节数与取值范围。
3. 区分 `signed` 与 `unsigned`，预测一次混合运算的结果。
4. 解释「C 只有值传递」，并说明为什么指针能「改变调用者的变量」。
5. 说清 `static` / `extern` / `const` 各自作用在什么上。

## 前置知识

- 任意语言的变量、函数、循环概念。
- 能在命令行编译并运行一个程序（见 [08-编译与链接](08-编译与链接.md)）。

## 核心概念

### 1. 程序结构：编译单元与 `main`

一个 C 程序由若干**编译单元**（translation unit）组成，每个 `.c` 文件是一个编译单元。程序从 `main` 开始执行，`main` 的返回值是进程退出码（`0` 表示成功）。

```c
#include <stdio.h>          // 预处理：把 stdio.h 的内容插进来

int add(int a, int b);      // 函数声明（declaration），只说明「有这么个函数」

int main(void) {            // 定义（definition），有函数体
    int sum = add(2, 3);
    printf("%d\n", sum);
    return 0;
}

int add(int a, int b) {     // 定义
    return a + b;
}
```

**声明与定义的区别**是后面链接（模块 08）的基础：声明告诉编译器「类型长这样」，定义真正分配空间或给出函数体。同一个函数可以声明多次，只能定义一次。

### 2. 基本类型与大小

C 只规定了**最小保证**，具体字节数依赖平台。在 x86-64 Linux（15-213 的环境）上：

| 类型 | 字节 | 取值范围（x86-64 Linux） |
| --- | --- | --- |
| `char` | 1 | −128 … 127（或 0 … 255，取决于是否有符号） |
| `short` | 2 | −32768 … 32767 |
| `int` | 4 | −2 147 483 648 … 2 147 483 647 |
| `long` | 8 | 与 `long long` 相同（LP64 模型） |
| `float` | 4 | 约 ±3.4×10³⁸，7 位有效数字 |
| `double` | 8 | 约 ±1.8×10³⁰⁸，15 位有效数字 |
| 指针 | 8 | 64 位地址 |

**`char` 是否有符号由实现决定。** 需要明确时用 `signed char` 或 `unsigned char`。15-213 的 `datalab` 就要求你在有符号/无符号之间精确转换。

用 `sizeof` 确认而不是背：

```c
#include <stdio.h>
int main(void) {
    printf("char=%zu int=%zu long=%zu float=%zu double=%zu ptr=%zu\n",
           sizeof(char), sizeof(int), sizeof(long), sizeof(float),
           sizeof(double), sizeof(void *));
    return 0;
}
```

### 3. `signed` 与 `unsigned`：混合运算的陷阱

无符号类型的运算**按 2ⁿ 取模**，不会「变成负数」。最经典的坑：

```c
#include <stdio.h>
int main(void) {
    unsigned int a = 1;
    int b = -1;
    if (a > b) printf("a > b\n");   // 你以为会打印，实际不会
    else       printf("a <= b\n");  // 实际打印这句
    return 0;
}
```

原因：`b` 在比较时被转换成 `unsigned int`，`-1` 变成 `4294967295`。

**规则**（C 的 usual arithmetic conversions）：`int` 与 `unsigned int` 运算时，`int` 转为 `unsigned int`。15-213 的 `datalab` 里大量题目就是靠这条规则设陷阱。

### 4. 运算符优先级与结合性

不需要背全表，但要记住三个高频错误：

| 写法 | 实际含义 | 想要什么 |
| --- | --- | --- |
| `*p++` | `*(p++)`：先取 `*p`，再让 `p` 前移 | 取决于意图 |
| `*p + 1` | `(*p) + 1` | 同上 |
| `a & b == c` | `a & (b == c)`：`==` 优先级高于 `&` | `(a & b) == c` |

**建议**：位运算和移位一律加括号。`-Wall` 会提示 `&` 与 `==` 混用。

### 5. 控制流

```c
for (int i = 0; i < n; i++) { /* ... */ }   // C99 起可在 for 内声明
while (cond) { /* ... */ }
do { /* ... */ } while (cond);
switch (x) {
    case 1: /* ... */ break;               // 忘了 break 会「贯穿」（fallthrough）
    default: /* ... */;
}
```

`switch` 的 `fallthrough` 是 15-213 常见 bug 来源；有意贯穿时加注释或 `/* fall through */`，`-Wimplicit-fallthrough` 可检测。

### 6. 函数与「只有值传递」

C **只有值传递**（call by value）。函数收到的是实参的**副本**。

```c
void bad_swap(int a, int b) { int t = a; a = b; b = t; }   // 无效
void good_swap(int *a, int *b) { int t = *a; *a = *b; *b = t; }  // 有效
```

`good_swap` 之所以有效，不是「传了引用」，而是**传了地址的副本**：副本指向同一块内存，所以能改内存里的值。这个区别是模块 03 的全部内容。

### 7. 作用域、存储期与链接

三个概念常被混为一谈：

| 概念 | 问的是什么 | 取值 |
| --- | --- | --- |
| 作用域（scope） | 名字在源码的哪些位置可见 | 块作用域、文件作用域、函数原型作用域 |
| 存储期（storage duration） | 对象活多久 | 自动（automatic）、静态（static）、动态（allocated） |
| 链接（linkage） | 名字能否跨文件使用 | 外部（external）、内部（internal）、无链接 |

`static` 在函数内 = 「存储期变成静态，只初始化一次」；在文件作用域 = 「链接变成内部，别的文件看不到」。**同一个关键字，两种含义**，这是 C 的经典混淆点。

```c
#include <stdio.h>
void counter(void) {
    static int n = 0;      // 只初始化一次，跨调用保留
    n++;
    printf("n=%d\n", n);
}
int main(void) { counter(); counter(); counter(); return 0; }  // 1 2 3
```

### 8. `const` 与限定符

`const` 表示「通过这个名字不能修改」，不是「这块内存不可变」。

```c
const int n = 10;        // n 不能改
int *p = (int *)&n;      // 强转后仍可写（未定义行为，别这么做）
```

指针与 `const` 的组合在 [03-指针](03-指针.md) 展开。

| definition | 定义 | 真正分配空间或给出函数体 |

| storage duration | 存储期 | 对象活多久 |

## 通俗类比

- **值传递** = 复印一份文件给对方，对方在复印件上改，你的原件不变。传指针 = 把「原件存放在哪个柜子」的纸条给对方，对方按地址去改原件。
- **`static` 局部变量** = 一个放在抽屉里的计数器，函数每次进来都从抽屉里接着数，而不是每次重新买一个。

## 原理讲解

### 程序从 `main` 到退出发生了什么

1. 操作系统加载可执行文件，把代码段、数据段映射进内存。
2. 调用 C 运行时启动代码（`_start`），它准备 `argc` / `argv` 和栈。
3. 调用 `main`。
4. `main` 返回，运行时调用 `exit`，把返回值交给操作系统。

第 2 步的细节在 15-213 的「Machine Programming: Procedures」和「Exceptional Control Flow」讲；这里只需要知道 `main` 不是真正的入口。

### 一次函数调用的栈变化

```c
int add(int a, int b) { return a + b; }
int main(void) { int r = add(2, 3); return 0; }
```

```text
调用 add 之前           调用 add 期间
+----------------+      +----------------+
| main 的栈帧     |      | main 的栈帧     |
|  r = ?          |      |  r = ?          |
+----------------+      +----------------+
                        | add 的栈帧      |  <- rsp 下移
                        |  a = 2 (副本)   |
                        |  b = 3 (副本)   |
                        |  返回地址        |
                        +----------------+
```

**关键**：`a`、`b` 是实参的副本，放在 `add` 的栈帧里；`add` 返回后整个栈帧被回收，`a`、`b` 就不存在了。这就是「不能返回局部变量地址」的原因（模块 05）。

## 代码示例

```c
/* day01_basics.c —— 用 -std=c11 -Wall -Wextra -Wpedantic 编译 */
#include <stdio.h>
#include <stdbool.h>
#include <limits.h>

static int max_of(const int *arr, int n) {   /* 只读数组，n 由调用者保证 >= 1 */
    int best = arr[0];
    for (int i = 1; i < n; i++) {
        if (arr[i] > best) best = arr[i];
    }
    return best;
}

int main(void) {
    int data[] = {3, 7, 1, 9, 4};
    const int n = (int)(sizeof data / sizeof data[0]);

    printf("max = %d\n", max_of(data, n));
    printf("INT_MAX = %d, INT_MIN = %d\n", INT_MAX, INT_MIN);
    printf("sizeof(int) = %zu\n", sizeof(int));

    bool ok = (n == 5);
    printf("n == 5 ? %s\n", ok ? "yes" : "no");
    return 0;
}
```

## 逐行代码解释

| 行 | 说明 |
| --- | --- |
| `static int max_of(...)` | `static` 让这个函数只在当前文件可见（内部链接） |
| `const int *arr` | 指针指向的内容不可通过 `arr` 修改；`arr` 本身可以改指向 |
| `int n` | 元素个数；C 的数组不携带长度，必须另传 |
| `arr[0]` | 调用者必须保证 `n >= 1`，否则越界（本函数用注释声明前置条件） |
| `sizeof data / sizeof data[0]` | 数组总字节数 ÷ 单元素字节数 = 元素个数；**只在数组未退化为指针时成立** |
| `%zu` | `sizeof` 的结果类型是 `size_t`，用 `%zu` 打印 |
| `bool` / `true` / `false` | C99 起需要 `#include <stdbool.h>` |

## 常见错误

| 错误 | 现象 | 正确做法 |
| --- | --- | --- |
| 忘记 `#include <stdio.h>` | 隐式声明 `printf`，C99 起是错误 | 一律包含对应头文件 |
| `int` 与 `unsigned` 比较 | 负数被转成巨大正数 | 显式转换或统一类型 |
| `if (a = b)` | 赋值当比较，`-Wall` 会警告 | 写 `if (a == b)`，或用 `if (b == a)` 写法 |
| 忘记 `break` | `switch` 贯穿 | 每个 `case` 显式 `break` |
| `main` 不写 `return` | C99 起 `main` 默认返回 0，但显式写更清楚 | 写 `return 0;` |
| 在 `for` 外使用循环变量 | C99 起循环变量作用域只在 `for` 内 | 需要时在外部声明 |

## 边界情况

- **`int` 溢出**：有符号溢出是**未定义行为**（UB），不是「回绕」。`-fwrapv` 可让它回绕，但不要依赖。
- **除零**：整数除零是 UB（通常直接崩溃）；浮点除零得到 `inf` / `nan`。
- **`char` 的符号**：`char c = 200;` 在 `char` 有符号的平台上会变成负数。
- **`sizeof` 与空结构体**：标准 C 不允许空结构体；GCC 扩展允许且大小为 0。

## 本节总结

- C 只有**值传递**，指针能改调用者的内存是因为传的是**地址的副本**。
- `int` / `unsigned int` 混合运算会把负数变成巨大正数。
- `static` 有两种含义：存储期（函数内）与链接（文件作用域）。
- 有符号整数溢出是**未定义行为**，不是回绕。
