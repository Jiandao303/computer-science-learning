# 03 指针

> **本模块是最高优先级。** 指针不是「一个难语法」，而是「用地址间接访问内存」这一机制。不把这一层想清楚，后面的链表、`malloc`、函数指针全都会退化成背代码。

## 学习目标

1. 说清「指针变量」本身存的是什么、占几个字节。
2. 解释 `&` 与 `*` 分别做什么，`*` 在声明与表达式中含义为何不同。
3. 手算指针算术：`p + 1` 前进多少字节取决于什么。
4. 写出二级指针的用途（修改指针本身，而不是它指向的内容）。
5. 分清 `const int *p`、`int *const p`、`const int *const p`。
6. 识别野指针（wild pointer）与悬空指针（dangling pointer）。

## 核心概念

### 1. 指针变量存的是地址

```c
int x = 42;        /* x 在地址 0x7ffd1234，占 4 字节，值为 42 */
int *p = &x;       /* p 在地址 0x7ffd1238，占 8 字节，值为 0x7ffd1234 */
```

```text
地址          内容
0x7ffd1234    42            <- x（4 字节）
0x7ffd1238    0x7ffd1234    <- p（8 字节，存的是 x 的地址）
```

**指针变量本身也是一块内存**，它存的值是另一个对象的地址。这就是「二级指针」的由来：指向指针的指针。

### 2. `&` 与 `*`

| 运算符 | 名称 | 作用 | 例子 |
| --- | --- | --- | --- |
| `&x` | address-of（取地址） | 得到 `x` 的地址，类型 `int *` | `int *p = &x;` |
| `*p` | dereference（解引用） | 访问 `p` 指向的对象 | `*p = 43;` 改的是 `x` |

**`*` 在声明里不是解引用**：

```c
int *p;    /* 声明：p 的类型是「指向 int 的指针」 */
*p = 5;    /* 表达式：解引用 p */
```

初学者最常见的困惑来自把 `int *p` 读成「`*p` 是 int」——这在声明语境下是错的。正确读法是「`p` 是 `int *`」。

### 3. 指针类型决定两件事

指针的类型 `T *` 决定：

1. **解引用时访问多少字节**（`sizeof(T)`）。
2. **指针算术时步长是多少**（也是 `sizeof(T)`）。

```c
int *pi;    pi + 1 前进 4 字节
char *pc;   pc + 1 前进 1 字节
double *pd; pd + 1 前进 8 字节
```

**所以 `p + 1` 不是「地址加 1」，而是「前进一个 `T`」。** 这是 15-213 `datalab` 与指针题的核心。

### 4. 指针算术

对 `T *p`：

| 表达式 | 含义 | 类型 |
| --- | --- | --- |
| `p + n` | 前进 `n * sizeof(T)` 字节 | `T *` |
| `p - n` | 后退 `n * sizeof(T)` 字节 | `T *` |
| `p - q` | 两个指针之间的**元素个数** | `ptrdiff_t` |
| `p[i]` | `*(p + i)` | `T` |
| `p++` / `++p` | 先取值后前移 / 先前移后取值 | `T *` |

**两个指针相减只在同一数组内合法**；不同数组相减是 UB。

```c
int a[5] = {10,20,30,40,50};
int *p = a;
printf("%d\n", *(p + 2));   /* 30 */
printf("%td\n", &a[4] - &a[1]);  /* 3（元素个数，不是字节数） */
```

### 5. 二级指针

`int **pp` 指向一个 `int *`。用途只有一个：**修改指针本身**。

```c
void set_to_null(int **pp) { *pp = NULL; }   /* 改的是调用者的指针变量 */

int *p = &some_int;
set_to_null(&p);      /* p 现在为 NULL */
```

如果只传 `int *p`，函数内改 `p` 只改副本。这是「二级指针」存在的唯一理由。

### 6. `const` 与指针

从右往左读：

| 声明 | 读法 | 能改 `p` | 能改 `*p` |
| --- | --- | --- | --- |
| `const int *p` | p 指向 const int | ✅ | ❌ |
| `int *const p` | p 是 const 指针，指向 int | ❌ | ✅ |
| `const int *const p` | 都是 const | ❌ | ❌ |

记忆法：`const` 修饰它**左边**的东西；左边没有东西就修饰右边。

```c
const int *p;        /* *p 不能改 */
int *const p = &x;   /* p 不能改 */
```

### 7. 野指针与悬空指针

| 名称 | 定义 | 例子 |
| --- | --- | --- |
| 野指针（wild pointer） | 从未初始化的指针 | `int *p; *p = 1;` |
| 悬空指针（dangling pointer） | 指向已释放或已失效内存的指针 | `free(p); *p = 1;` |
| 空指针（null pointer） | 明确指向「无」 | `int *p = NULL;` |

**规则**：

- 声明指针就初始化（`= NULL` 或有效地址）。
- `free` 之后立刻置 `NULL`。
- 不返回局部变量的地址。

```c
int *bad(void) { int x = 5; return &x; }   /* 返回后 x 的栈帧已回收 */
```

## 通俗类比

- 指针 = 门牌号。`p = &x` 是把 `x` 的门牌号抄在 `p` 上；`*p = 43` 是按门牌号找过去，把屋里的东西换掉。
- 二级指针 = 一张写着「门牌号放在哪个抽屉」的纸条。要改「门牌号本身」，得知道它在哪个抽屉。
- 悬空指针 = 房子已经拆了，门牌号还留着。按它找过去是废墟。

## 原理讲解

### 一次解引用的机器级过程

```c
int x = 42;
int *p = &x;
int y = *p;
```

```asm
; x86-64（示意，非逐条精确）
movl    $42, -4(%rbp)      ; x = 42
leaq    -4(%rbp), %rax     ; rax = &x
movq    %rax, -16(%rbp)    ; p = rax
movq    -16(%rbp), %rax    ; rax = p
movl    (%rax), %eax       ; eax = *p
movl    %eax, -8(%rbp)     ; y = eax
```

**两步**：先从 `p` 所在内存取出地址，再用这个地址去取数据。这就是「间接访问」的代价——多一次内存访问。

### 指针算术为什么按元素步长

编译器知道 `p` 的类型是 `int *`，所以 `p + 1` 被编译成「地址 + 4」。如果写成 `(char *)p + 1`，才是「地址 + 1」。

```c
int a[3] = {1,2,3};
int *p = a;
char *cp = (char *)a;
printf("%p %p\n", (void *)(p + 1), (void *)(cp + 1));
/* p+1 比 a 大 4；cp+1 比 a 大 1 */
```

### 数组与指针的等价与不等价

| 场景 | 等价？ |
| --- | --- |
| `a[i]` 与 `*(a + i)` | ✅ 完全等价 |
| `a` 与 `&a[0]` | ✅ 值相同 |
| `sizeof(a)` 与 `sizeof(&a[0])` | ❌ 前者是数组大小，后者是 8 |
| `&a` 与 `a` | ❌ 类型不同（`int (*)[N]` vs `int *`），值相同 |
| 数组可赋值给指针 | ✅ |
| 指针可赋值给数组 | ❌ 数组不是可修改左值 |

## 代码示例

```c
/* day03_pointers.c */
#include <stdio.h>
#include <stddef.h>

static void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}

static void reset(int **pp) {
    *pp = NULL;                  /* 修改调用者的指针本身 */
}

static int sum_array(const int *arr, size_t n) {
    int s = 0;
    for (size_t i = 0; i < n; i++) s += arr[i];
    return s;
}

int main(void) {
    int x = 1, y = 2;
    swap(&x, &y);
    printf("after swap: x=%d y=%d\n", x, y);

    int *p = &x;
    reset(&p);
    printf("after reset: p is %s\n", p == NULL ? "NULL" : "non-NULL");

    int a[5] = {1, 2, 3, 4, 5};
    printf("sum = %d\n", sum_array(a, 5));
    printf("p[2] - p[0] = %td\n", &a[2] - &a[0]);
    printf("sizeof(a)=%zu sizeof(&a[0])=%zu\n", sizeof a, sizeof &a[0]);
    return 0;
}
```

## 逐行代码解释

| 行 | 说明 |
| --- | --- |
| `void swap(int *a, int *b)` | 参数是指针，函数内 `*a` 就是调用者的变量 |
| `int t = *a;` | 先保存 `*a` 的值，否则第一次赋值会覆盖 |
| `*pp = NULL;` | `*pp` 就是调用者的指针变量；改它才能改「指向」 |
| `const int *arr` | 函数承诺不通过 `arr` 修改数组 |
| `&a[2] - &a[0]` | 结果是 `ptrdiff_t`（元素个数），用 `%td` |
| `sizeof &a[0]` | 8（指针大小），对比 `sizeof a` = 20 |

## 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| `int *p; *p = 1;` | 野指针写入，段错误或静默破坏 | 初始化 `= NULL` 或有效地址 |
| `free(p); *p = 1;` | 悬空指针（use-after-free） | `free(p); p = NULL;` |
| `return &local;` | 返回已回收栈帧的地址 | 返回堆内存或让调用者传缓冲区 |
| `p + 1` 以为前进 1 字节 | 差 `sizeof(T)` 倍 | 需要字节级用 `(char *)p + 1` |
| `int *p = 0x1234;` | 整数转指针，警告且危险 | 只在必要时强转，并说明来源 |
| 比较两个不同数组的指针 | UB | 只在同一数组内比较 |

## 边界情况

- **`NULL` 解引用**：`*NULL` 一定是崩溃（UB），不要写「返回 0」。
- **`p[-1]`**：语法合法，越界与否取决于 `p` 的位置。
- **`void *` 算术**：GNU C 允许 `void *` 加减（按 1 字节），**标准 C 不允许**。本库不用。
- **函数指针与数据指针互转**：标准不保证，POSIX 上可行。
- **指针的打印**：用 `%p`，并转成 `(void *)`。

## 本节总结

- 指针是**存地址的变量**，本身占 8 字节（x86-64）。
- `*` 在声明与表达式中含义不同。
- 指针算术的步长 = `sizeof(T)`。
- 二级指针的唯一用途是**修改指针本身**。
- `const` 从右往左读；野指针与悬空指针是最常见的内存 bug。
