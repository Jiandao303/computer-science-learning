# 02 数组与字符串

> 对应模块 02。核心只有一句话：**数组不是指针，但几乎所有表达式里它都会退化成指针。**

## 学习目标

1. 画出 `int a[5]` 与 `char s[] = "abc"` 的内存布局。
2. 解释「数组名在什么情况下不退化为指针」（`sizeof`、`&`、字符串字面量初始化）。
3. 正确使用 `strlen` / `strcmp` / `strcpy` / `strncpy` / `memcpy` / `memset`。
4. 说出 `strncpy` 的三个反直觉行为。
5. 识别并避免缓冲区溢出（buffer overflow）。

## 前置知识

- [01-基础语法](01-基础语法.md) 的类型与作用域。
- 知道 `char` 占 1 字节。

## 核心概念

### 1. 数组的内存布局

`int a[5] = {10, 20, 30, 40, 50};` 在内存中是**连续**的 20 字节：

```text
低地址                                              高地址
+--------+--------+--------+--------+--------+
|   10   |   20   |   30   |   40   |   50   |   每个 4 字节
+--------+--------+--------+--------+--------+
 a[0]     a[1]     a[2]     a[3]     a[4]
 ^
 &a[0] == a （数组名在表达式中退化为指向首元素的指针）
```

**数组不携带长度信息**。`sizeof a` 能算出 20 字节，但一旦把 `a` 传给函数，函数只收到一个指针，`sizeof` 就变成 8 了。

### 2. 数组退化为指针

在**几乎所有表达式**中，数组名会转换成指向首元素的指针：

| 表达式 | 类型 | 说明 |
| --- | --- | --- |
| `a` | `int *` | 退化为 `&a[0]` |
| `sizeof a` | `size_t` | **不退化**，得到整个数组的字节数 |
| `&a` | `int (*)[5]` | **不退化**，得到「指向整个数组的指针」 |
| `"abc"` | `char[4]` | 字符串字面量的类型是数组，不是指针 |

```c
#include <stdio.h>
void f(int arr[5]) {          /* 等价于 int *arr，5 被忽略 */
    printf("sizeof(arr) = %zu\n", sizeof(arr));   /* 8，不是 20 */
}
int main(void) {
    int a[5] = {0};
    printf("sizeof(a) = %zu\n", sizeof(a));       /* 20 */
    f(a);
    return 0;
}
```

**这就是「数组作为参数必须另传长度」的原因。**

### 3. `a[i]` 到底是什么

`a[i]` 的定义是 `*(a + i)`。因为 `+` 可交换，所以 `i[a]` 也合法（但不要这么写）。

这条定义解释了三件事：

1. `a[0]` 与 `*a` 等价。
2. 越界访问 `a[5]` 是 `*(a + 5)`，编译器**不检查**。
3. 指针可以当数组用：`int *p = a; p[2]` 就是 `a[2]`。

### 4. 字符串：`\0` 约定

C 没有「字符串类型」，字符串是**以 `\0` 结尾的 `char` 数组**。

```c
char s1[] = "abc";      /* 4 字节：'a' 'b' 'c' '\0' */
char s2[3] = "abc";     /* 3 字节，没有 '\0' —— 不是字符串，是字符数组 */
char *s3 = "abc";       /* 指向只读区，s3[0] = 'x' 是 UB */
```

```text
s1:  +-----+-----+-----+------+
     | 'a' | 'b' | 'c' | '\0' |
     +-----+-----+-----+------+
       s1[0] s1[1] s1[2] s1[3]
```

**三个必须记住的差异**：

| 写法 | 可修改 | 长度 | 存储位置 |
| --- | --- | --- | --- |
| `char s[] = "abc";` | ✅ | 4（含 `\0`） | 栈（或静态区，取决于作用域） |
| `char *s = "abc";` | ❌（UB） | 指向 4 字节字面量 | 只读数据段 |
| `char s[3] = "abc";` | ✅ | 3，**无 `\0`** | 栈 |

### 5. `<string.h>` 的正确用法

| 函数 | 原型 | 陷阱 |
| --- | --- | --- |
| `strlen` | `size_t strlen(const char *s)` | 不把 `\0` 计入；`s` 必须有 `\0` |
| `strcmp` | `int strcmp(const char *a, const char *b)` | 返回 0 表示相等；**不要用 `==` 比较字符串** |
| `strcpy` | `char *strcpy(char *dst, const char *src)` | 不检查 `dst` 容量 → 溢出 |
| `strncpy` | `char *strncpy(char *dst, const char *src, size_t n)` | 见下 |
| `memcpy` | `void *memcpy(void *dst, const void *src, size_t n)` | 区域重叠时是 UB，用 `memmove` |
| `memset` | `void *memset(void *s, int c, size_t n)` | 只能按字节填充；`memset(arr, 1, n)` 不是把每个 `int` 设为 1 |

**`strncpy` 的三个反直觉行为**（Boot Camp p34–p35 专门讲）：

1. 如果 `src` 比 `n` 短，**剩余部分用 `\0` 填满**（不是只补一个）。
2. 如果 `src` 不短于 `n`，**不补 `\0`**，结果不是合法字符串。
3. 所以 `strncpy(dst, src, sizeof dst)` 之后**必须手动 `dst[sizeof dst - 1] = '\0'`**。

```c
char dst[8];
strncpy(dst, "abcdefghij", sizeof dst - 1);  /* 留 1 字节 */
dst[sizeof dst - 1] = '\0';                  /* 手动终止 */
```

## 通俗类比

数组像一排连续的储物柜，编号从 0 开始。数组名是「第 0 号柜的位置」；`a[3]` 是「从 0 号柜往前走 3 格」。因为柜子紧挨着，走过头就会闯进别人的柜子——这就是越界。

## 原理讲解

### 为什么 `sizeof(a)/sizeof(a[0])` 在函数里失效

```c
void f(int a[10]) {                 /* 编译器把它改写成 int *a */
    size_t n = sizeof(a) / sizeof(a[0]);   /* 8 / 4 = 2，错的 */
}
```

C 标准规定：函数参数中的数组类型**自动调整为指针类型**。所以 `sizeof(a)` 得到的是指针大小。

**正确做法**：要么另传 `n`，要么用结构体把长度和数组包在一起：

```c
typedef struct {
    int *data;
    size_t len;
} IntArray;
```

### `memcpy` vs `memmove`

`memcpy` 假定源和目标**不重叠**；重叠时用 `memmove`（它内部判断方向）。

```c
char buf[10] = "abcdefghi";
memcpy(buf + 1, buf, 5);    /* UB：区域重叠 */
memmove(buf + 1, buf, 5);   /* 正确 */
```

## 内存示意图

```c
char s[] = "hello";
char *p = s;
```

```text
栈：
+-----+-----+-----+-----+-----+------+
| 'h' | 'e' | 'l' | 'l' | 'o' | '\0' |
+-----+-----+-----+-----+-----+------+
  ^     ^
  s     s+1

（p 是一个 8 字节的指针变量，存放在另一处）
```

二维数组 `int m[2][3]`：

```text
m[0][0] m[0][1] m[0][2] m[1][0] m[1][1] m[1][2]
+-------+-------+-------+-------+-------+-------+
|   1   |   2   |   3   |   4   |   5   |   6   |
+-------+-------+-------+-------+-------+-------+
<--------- 第 0 行 ---------><------- 第 1 行 ------>

```

## 代码示例

```c
/* day02_strings.c */
#include <stdio.h>
#include <string.h>

static size_t count_char(const char *s, char target) {
    size_t n = 0;
    for (size_t i = 0; s[i] != '\0'; i++) {
        if (s[i] == target) n++;
    }
    return n;
}

static void safe_copy(char *dst, size_t dst_size, const char *src) {
    if (dst_size == 0) return;
    strncpy(dst, src, dst_size - 1);
    dst[dst_size - 1] = '\0';
}

int main(void) {
    char text[] = "hello world";
    printf("len = %zu\n", strlen(text));
    printf("count 'l' = %zu\n", count_char(text, 'l'));

    char buf[8];
    safe_copy(buf, sizeof buf, "a very long string");
    printf("buf = \"%s\" (len %zu)\n", buf, strlen(buf));

    printf("strcmp(\"abc\",\"abd\") = %d\n", strcmp("abc", "abd"));
    return 0;
}
```

## 逐行代码解释

| 行 | 说明 |
| --- | --- |
| `s[i] != '\0'` | 逐字符扫描直到空字符；`s` 必须有 `\0` |
| `size_t i` | 下标用 `size_t` 避免有符号/无符号比较警告 |
| `strncpy(dst, src, dst_size - 1)` | 只复制 `dst_size-1` 字节，留出终止符位置 |
| `dst[dst_size - 1] = '\0'` | 强制终止；`strncpy` 在截断时不补 `\0` |
| `strcmp("abc","abd")` | 返回负数（`'c' < 'd'`），不是 −1 |

## 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| `char s[3] = "abc";` 后当字符串用 | 无 `\0`，`strlen` 越界读 | 留一字节给 `\0` |
| `if (s1 == s2)` 比较字符串 | 比较的是地址 | 用 `strcmp` |
| `strcpy(dst, src)` 不检查容量 | 缓冲区溢出 | 用 `strncpy` + 手动终止，或 `snprintf` |
| `memset(arr, 1, sizeof arr)` | 每个字节设 1，`int` 变成 `0x01010101` | 用循环或 `memset(arr, 0, ...)` |
| `memcpy` 处理重叠区域 | UB | 用 `memmove` |
| `sizeof(ptr)` 当数组长度 | 得到 8 | 另传长度 |

## 边界情况

- **空字符串** `""` 占 1 字节（只有 `\0`），`strlen` 返回 0。
- **`strlen` 返回 `size_t`**（无符号），`strlen(a) - strlen(b)` 在 `a` 短于 `b` 时会变成巨大正数。
- **`char` 为有符号时**，`s[i] != '\0'` 仍正确，但 `s[i] < 0` 可能出现在 UTF-8 多字节字符上。
- **二维数组传参**：`void f(int m[][3])` 必须给出除第一维外的所有维度。

## 本节总结

- 数组在表达式中**退化为指针**，只有 `sizeof`、`&`、初始化时例外。
- `a[i]` 就是 `*(a+i)`；越界编译器不检查。
- 字符串 = 以 `\0` 结尾的 `char` 数组。
- `strncpy` 不保证 `\0`，**必须手动终止**。
