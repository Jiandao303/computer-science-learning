# 06 二进制与位运算

> **本模块是 15-213 的直接前置。** `datalab` 全部建立在这里：补码、无符号回绕、移位、掩码。这些不是「知道概念」就够，要能**手算**。

## 学习目标

1. 在二进制、十进制、十六进制之间自由转换。

4. 判断一次运算是否溢出，并说明有符号溢出为何是 UB。
5. 解释算术右移与逻辑右移的区别。

## 核心概念

### 1. 进制

| 进制 | 前缀 | 例子 | 十进制值 |
| --- | --- | --- | --- |
| 二进制 | `0b` | `0b1011` | 11 |
| 八进制 | `0` | `013` | 11 |
| 十进制 | 无 | `11` | 11 |
| 十六进制 | `0x` | `0xB` | 11 |

**一个十六进制位 = 4 个二进制位**，这是十六进制在系统编程里通用的原因：`0xDEADBEEF` 一眼能看出每 4 位。

### 2. 无符号与有符号的位模式

32 位 `unsigned int` 的值 = 按二进制直接解释。
32 位 `int` 用**补码**（two's complement）：

- 最高位是符号位：0 为正，1 为负。
- 负数的值 = `-2^31 + 其余位的值`。

```text
0xFFFFFFFF (32 位全 1)
  as unsigned: 4294967295
  as int:      -1

0x80000000
  as unsigned: 2147483648
  as int:      -2147483648 (INT_MIN)
```

### 3. 补码的三条核心公式

设 `x` 是 32 位整数：

| 公式 | 含义 |
| --- | --- |
| `-x = ~x + 1` | 取负 = 按位取反再加 1 |
| `~x = -x - 1` | 取反 = 取负再减 1 |
| `x + (~x) = -1`（全 1） | 自明 |

**验证**（实测输出）：`x = 5` 时 `~5 = -6`，`~5 + 1 = -5`，正好是 `-x`。

```text
5, ~5, ~5+1 = 5, -6, -5
```

**注意**：`-x = ~x + 1` 是对 **`x` 本身**成立。不要写成 `~(-5) + 1`——那是 `4 + 1 = 5`，正好是 `-(-5)`，也成立，但不是「求 -5 的补码」。

### 4. 位运算

| 运算 | 符号 | 规则 | 用途 |
| --- | --- | --- | --- |
| 按位与 | `&` | 全 1 才 1 | 取位、清位 |
| 按位或 | `\|` | 有 1 就 1 | 置位 |
| 按位异或 | `^` | 不同为 1 | 翻转位、交换 |
| 按位取反 | `~` | 0↔1 | 配合掩码 |
| 左移 | `<<` | 低位补 0 | 乘 2ⁿ |
| 右移 | `>>` | 见下 | 除 2ⁿ |

### 5. 掩码三件套

```c
#define MASK(n) (1u << (n))

x |=  MASK(3);     /* 置位：把第 3 位置 1 */
x &= ~MASK(3);     /* 清位：把第 3 位置 0 */
x ^=  MASK(3);     /* 翻转：第 3 位取反 */
if (x & MASK(3))   /* 检测：第 3 位是否为 1 */
```

**取连续 k 位**：`(x >> start) & ((1u << k) - 1)`。

```c
/* 取 x 的第 4..7 位（4 位） */
unsigned field = (x >> 4) & 0xF;
```

### 6. 移位

**左移 `x << n`**：低位补 0。若移出的位非零，行为是 UB（对有符号）或按 2³² 取模（对无符号）。

**右移 `x >> n`**：

| 类型 | 行为 | 名称 |
| --- | --- | --- |
| 无符号 | 高位补 0 | 逻辑右移（logical shift） |
| 有符号非负 | 高位补 0 | — |
| 有符号负数 | **实现定义**（GCC 补符号位） | 算术右移（arithmetic shift） |

**15-213 要求**：写 `x >> n` 时，如果 `x` 可能为负，先用无符号处理，避免依赖实现。

### 7. 整数溢出

| 情况 | 结果 |
| --- | --- |
| 无符号溢出 | **定义良好**：按 2ⁿ 取模 |
| 有符号溢出 | **未定义行为（UB）** |

```c
unsigned u = UINT_MAX;
u + 1;              /* 0，定义良好 */

int i = INT_MAX;
i + 1;              /* UB，编译器可以做任何事 */
```

**检测无符号加法溢出**：`if (a + b < a)`。
**检测有符号加法溢出**：不能靠结果判断，要用 `__builtin_add_overflow`（GCC）或在运算前比较。

## 英文术语与中文解释

| 英文 | 中文 | 一句话 |
| --- | --- | --- |
| two's complement | 补码 | 负数 = 取反加一 |
| bitwise AND/OR/XOR | 按位与/或/异或 | 逐位运算 |
| bit mask | 位掩码 | 用来选定位的模式 |
| logical shift | 逻辑右移 | 高位补 0 |
| arithmetic shift | 算术右移 | 高位补符号位 |
| overflow | 溢出 | 结果超出可表示范围 |
| wraparound | 回绕 | 无符号溢出后的取模行为 |
| sign extension | 符号扩展 | 小类型转大类型时复制符号位 |

## 通俗类比

- 位掩码 = 一张镂空的卡片。把它盖在数字上，只有镂空处的位能露出来（`&`）。
- 补码 = 钟表。把钟往回拨 1 小时，和往前拨 11 小时结果一样；`-1` 就是 `+4294967295`。

## 原理讲解

### 为什么补码能让减法变成加法

在模 2³² 的意义下，`-x` 与 `2³² - x` 等价。而 `2³² - x = ~x + 1`。

```text
x = 5            = 0x00000005
~x               = 0xFFFFFFFA
~x + 1           = 0xFFFFFFFB  = -5

验证：5 + 0xFFFFFFFB = 0x100000000 = 0 (mod 2^32)
```

所以 CPU 不需要单独的减法器，`a - b` 就是 `a + (~b + 1)`。

### 符号扩展

```c
int8_t  a = -1;    /* 0xFF */
int32_t b = a;     /* 0xFFFFFFFF，不是 0x000000FF */
```

**规则**：小类型转大类型时，若源类型有符号且为负，高位全部补 1。

```c
uint8_t ua = 0xFF;
uint32_t ub = ua;  /* 0x000000FF，高位补 0 */
```

**这是 15-213 `datalab` 的高频考点。**

### 算术右移的手算

```text
x = 0xFFFFFFF0  (-16)
x >> 4（算术）  = 0xFFFFFFFF  (-1)     <- 高位补符号位
x >> 4（逻辑）  = 0x0FFFFFFF  (268435455)
```

`-16 / 16 = -1`，算术右移给出正确结果；逻辑右移给出巨大正数。

## 代码示例

```c
/* day06_bits.c */
#include <stdio.h>
#include <stdint.h>
#include <limits.h>

static unsigned get_bits(unsigned x, int start, int len) {
    return (x >> start) & ((1u << len) - 1u);
}

static int is_negative(int x) {
    return (x >> 31) & 1;          /* 取符号位 */
}

static unsigned abs_unsigned(int x) {
    unsigned ux = (unsigned)x;
    unsigned mask = -(unsigned)(x < 0);   /* x<0 时为全 1，否则全 0 */
    return (ux ^ mask) + (mask & 1u);
}

int main(void) {
    unsigned x = 0x12345678u;
    printf("bits 4..7 = 0x%X\n", get_bits(x, 4, 4));
    printf("is_negative(-5) = %d\n", is_negative(-5));
    printf("abs(-7) = %u\n", abs_unsigned(-7));

    printf("UINT_MAX + 1 = %u\n", UINT_MAX + 1u);   /* 0，定义良好 */
    printf("-1 as unsigned = %u\n", (unsigned)-1);

    int8_t s = -1;
    printf("sign extend: 0x%X\n", (unsigned)(int32_t)s);
    return 0;
}
```

## 逐行代码解释

| 行 | 说明 |
| --- | --- |
| `(x >> start) & ((1u << len) - 1u)` | 右移到起点，再用 `len` 个 1 的掩码截取 |
| `(x >> 31) & 1` | 取最高位；对 `int` 需注意算术右移 |
| `-(unsigned)(x < 0)` | 利用「真为 1、假为 0」生成全 0 或全 1 掩码 |
| `(ux ^ mask) + (mask & 1u)` | 负数走「取反加一」，正数掩码为 0 不变 |
| `UINT_MAX + 1u` | 无符号回绕，结果为 0 |
| `(unsigned)(int32_t)s` | 先符号扩展到 32 位，再按无符号打印 |

## 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| `1 << 31` | `1` 是 `int`，左移到符号位是 UB | `1u << 31` |
| `x >> 31` 对负数当逻辑右移用 | 结果依赖实现 | 先转 `unsigned` |
| `~0` 以为是 0 | `~0` 是全 1 | 用 `0u` 表示 0 |
| `a & b == c` | 被解析成 `a & (b == c)` | 加括号 |
| 有符号溢出当回绕 | UB，优化器可能删代码 | 用无符号或显式检查 |
| `char` 直接参与位运算 | 符号扩展意外 | 转 `unsigned char` |

## 边界情况

- **`1 << 31`**：`int` 的符号位，UB；用 `1u << 31`。
- **`x << 32`**：移位量 ≥ 位宽是 UB。
- **`INT_MIN` 取负**：`-INT_MIN` 溢出，UB。
- **`x / 2` 与 `x >> 1`**：负数时不等价（`-3 / 2 = -1`，`-3 >> 1 = -2`）。
- **位域（bit-field）**：布局由实现定义，跨平台不要用。

## 本节总结

- 补码的核心公式：`-x = ~x + 1`。
- 掩码三件套：`|=` 置位、`&= ~mask` 清位、`& mask` 检测。
- 有符号右移补符号位（实现定义），无符号补 0。
- 无符号溢出定义良好（取模），**有符号溢出是 UB**。
- 小类型转大类型时注意符号扩展。
