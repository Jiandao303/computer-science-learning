# 12 CMU 15-213 先修评估

> 用法：先做「自评」（10 分钟，凭印象），再逐项**实际动手验证**。
> **只有能当场写出来 / 讲清楚，才打勾。** 打勾不代表满分，代表「不会拖后腿」。

## 一、自评（10 分钟）

不看笔记，快速回答，记下「答不出」的题号：

1. 指针变量本身占几个字节？
2. `int *p; p + 1` 前进几个字节？
3. `a[i]` 展开成什么？
4. `char s[3] = "abc";` 能当字符串用吗？
5. `strncpy` 在截断时会补 `\0` 吗？
6. `malloc` 和 `calloc` 的唯一区别？
7. `realloc` 失败时原内存还在吗？
8. 进程内存有哪几段？
9. 局部变量、`malloc`、全局变量分别在哪一段？
10. 为什么不能返回局部变量的地址？
11. `-1` 的 32 位补码？
12. `-x` 与 `~x + 1` 的关系？
13. 有符号右移与无符号右移的区别？
14. 有符号溢出是什么行为？
15. `int8_t a = -1;` 转 `int32_t` 后是多少？
16. `void *` 能不能解引用？
17. `qsort` 的比较函数为什么不能返回 `x - y`？
18. 编译的四个阶段？
19. `undefined reference` 是什么原因？
20. 调试为什么必须用 `-g -O0`？

**自评判定**：

- 答出 ≥ 16 题 → 直接做第二节的动手验证。
- 答出 10–15 题 → 先复习对应的模块，再做验证。
- 答出 < 10 题 → 从 Day 1 开始，不要跳。

## 三、判定标准

| 通过项 | 判定 | 建议 |
| --- | --- | --- |
| 18–20 | ✅ 可以进 15-213 | 直接开始 Bootcamp 1 |
| 15–17 | ⚠ 基本够用 | 进 15-213，但把未过的项列成待补 |
| 10–14 | ⚠ 偏弱 | 先补 Day 3 与 Day 5，再进 |
| < 10 | ❌ 不建议直接进 | 完整走完八天路线 |

## 四、哪些可以进 15-213 后再学

| 内容 | 为什么可以推迟 |
| --- | --- |
| GDB 高级命令（`watch`、条件断点、`x` 的各种格式） | 课程会教，且 `bomblab` 就是练这个 |
| 静态库 / 动态库的细节 | Bootcamp 3 覆盖 |
| `getopt`、`<stdio.h>` 的完整家族 | 用到了再查 |
| `union` 的类型双关细节 | 课程只在特定 lab 用到 |
| 宏的高级用法（`##`、可变参数） | 课程不要求 |
| 多线程（`pthread`） | 15-213 后期才讲 |

## 五、哪些必须掌握（不能推迟）

| 内容 | 为什么不能推迟 |
| --- | --- |
| 补码与无符号运算 | `datalab` 第一周就用 |
| 指针算术与类型宽度 | 机器级编程全程用 |
| 内存布局（栈/堆/数据段） | `malloclab` 的核心 |
| `malloc` / `free` 的所有权 | `malloclab` 与 `cachelab` 都会踩坑 |
| 多文件编译与 `Makefile` | 所有 lab 的交付方式 |
| 用调试器而不是 `printf` | `bomblab` 不给你源码 |
