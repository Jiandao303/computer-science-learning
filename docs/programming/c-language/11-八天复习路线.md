# 11 八天复习路线

> 每天 60–90 分钟。**顺序不能跳**：Day 3（指针）与 Day 5（内存）没过关，后面的练习会变成抄代码。
> 每天固定流程：**读笔记（20–30 分钟）→ 敲例子（15 分钟）→ 做练习（30–40 分钟）→ 跑测试（10 分钟）**。

## 总览

| 天 | 主题 | 笔记 | 练习目录 | 必须掌握 |
| --- | --- | --- | --- | --- |
| Day 1 | 基础语法、变量、函数、循环 | [01-基础语法](01-基础语法.md) | `Day-01/` | 值传递、`static`、`signed/unsigned` |
| Day 2 | 数组、字符串、标准库 | [02-数组与字符串](02-数组与字符串.md) | `Day-02/` | 数组退化、`\0`、`strncpy` |
| Day 3 | 指针、地址、解引用、指针参数 | [03-指针](03-指针.md) | `Day-03/` | 指针算术、二级指针、`const` |
| Day 4 | 结构体、结构体指针、链表 | [04-结构体与数据结构](04-结构体与数据结构.md) | `Day-04/` | padding、链表释放 |
| Day 5 | 栈、堆、`malloc` / `calloc` / `realloc` / `free` | [05-内存管理](05-内存管理.md) | `Day-05/` | 所有权、`realloc` 陷阱 |
| Day 6 | 二进制、补码、位运算、类型转换 | [06-二进制与位运算](06-二进制与位运算.md) | `Day-06/` | 补码、掩码、符号扩展 |
| Day 7 | GCC、头文件、多文件、GDB、Valgrind | [08-编译与链接](08-编译与链接.md)、[09-GDB与Valgrind](09-GDB与Valgrind.md) | `Day-07/` | 四阶段、断点、泄漏检测 |
| Day 8 | 综合项目与入门评估 | [10-综合练习](10-综合练习.md)、[12-CMU-15-213先修评估](12-CMU-15-213先修评估.md) | `Day-08/` | 全部 |

> **Day 7 是两个模块合一天**，因为编译与调试本来就是同一件事的两面。如果时间不够，Day 7 可以拆成两天，总周期变成 9 天。

## Day 1：基础语法

**学习目标**：写出带函数、循环、条件分支的程序，并解释执行顺序。

**读**：[01-基础语法](01-基础语法.md) 的「核心概念」与「内存示意图」。

**做**：

| 练习 | 要求 |
| --- | --- |
| `ex1_types.c` | 打印 `char/short/int/long/float/double/ptr` 的 `sizeof` |
| `ex2_swap.c` | 写值传递与指针版本的 `swap`，对比结果 |
| `ex3_static.c` | 用 `static` 局部变量实现计数器 |

**自测**：

1. `unsigned int a = 1; int b = -1;` 时 `a > b` 为真吗？
2. 函数内 `static int n` 与文件作用域 `static int n` 有何不同？
3. 为什么 `bad_swap` 改不了调用者的变量？

**验收标准**：

- [ ] 三个练习都能用 `-std=c11 -Wall -Wextra -Wpedantic` **零警告**编译
- [ ] 能不看笔记说出「C 只有值传递」并解释指针为什么能改调用者的值
- [ ] 能正确回答上面 3 个自测题

---

## Day 2：数组与字符串

**学习目标**：处理数组、字符串与连续内存。

**读**：[02-数组与字符串](02-数组与字符串.md)。

**做**：

| 练习 | 要求 |
| --- | --- |
| `ex1_array_sum.c` | 求数组和与最大值，用 `sizeof` 算长度 |
| `ex2_str_funcs.c` | 手写 `my_strlen` / `my_strcmp` / `my_strcpy` |
| `ex3_strncpy_trap.c` | 复现 `strncpy` 不补 `\0`，再写安全版本 |

**自测**：

1. `sizeof(a)` 在 `main` 与在函数参数里分别是什么？
2. `char s[3] = "abc";` 能当字符串用吗？
3. `memcpy` 与 `memmove` 的区别？

**验收标准**：

- [ ] 能画出 `int a[5]` 与 `char s[] = "abc"` 的内存布局
- [ ] `ex3` 能演示 `strncpy` 的危险行为，且 `safe_copy` 正确
- [ ] 能解释 `a[i]` 为什么等于 `*(a+i)`

---

## Day 3：指针（最关键的一天）

**学习目标**：真正理解「指针存地址、通过地址访问数据」。

**读**：[03-指针](03-指针.md) 全部，**尤其「内存示意图」三张图**。

**做**：

| 练习 | 要求 |
| --- | --- |
| `ex1_swap_ptr.c` | `swap` 与 `swap_wrong` 对比 |
| `ex2_ptr_arith.c` | 用 `p++` 与 `p[i]` 两种写法遍历，打印每步地址 |
| `ex3_double_ptr.c` | 用二级指针实现链表头插 |
| `ex4_const.c` | 三种 `const` 组合，观察报错位置 |

**自测**：

1. `int *p; p + 1` 前进多少字节？
2. 什么时候必须用二级指针？
3. `const int *p` 与 `int *const p` 分别限制什么？

**验收标准**：

- [ ] 能徒手画出 `int x = 42; int *p = &x; int **pp = &p;` 的三层内存图
- [ ] 能解释 `p + 1` 的步长规则，并说出 `char *` 与 `int *` 的差别
- [ ] `ex3` 的链表头插正确，且用二级指针修改了 `head`

> **如果 Day 3 没过关，不要进入 Day 4。** 重复 Day 3，直到能不看笔记讲清三张图。

---

## Day 4：结构体与数据结构

**学习目标**：用结构体与指针组织数据。

**读**：[04-结构体与数据结构](04-结构体与数据结构.md)。

**做**：

| 练习 | 要求 |
| --- | --- |
| `ex1_struct_basic.c` | `Point` / `Rect`，算面积周长 |
| `ex2_struct_size.c` | 用 `offsetof` 验证 padding |
| `ex3_linked_list.c` | `push_front` / `push_back` / `remove` / `print` / `free` |
| `ex4_stack_queue.c` | 数组实现栈与环形队列 |

**自测**：

1. `struct { char c; int i; char d; }` 的 `sizeof` 是多少？为什么？
2. 释放链表时为什么先保存 `next`？
3. 二级指针删除节点消除了什么特殊分支？

**验收标准**：

- [ ] 能算出含 padding 的 `sizeof`，并用 `offsetof` 验证
- [ ] 链表五个操作全部正确，Valgrind/ASan 无泄漏（若已装）
- [ ] 能解释 `.` 与 `->` 的使用场景

---

## Day 5：内存管理（最关键的一天）

**学习目标**：理解申请、使用、管理、释放动态内存。

**读**：[05-内存管理](05-内存管理.md)，**重点看内存布局图与「四类内存错误」**。

**做**：

| 练习 | 要求 |
| --- | --- |
| `ex1_malloc_basic.c` | 分配、使用、释放，检查失败 |
| `ex2_realloc_grow.c` | 可增长数组，正确使用临时变量 |
| `ex3_leak_detect.c` | 故意泄漏，用 Valgrind 定位 |
| `ex4_ownership.c` | `dup_string`，注释写明所有权 |

**自测**：

1. 局部变量、`malloc`、全局变量分别在哪一段？
2. `p = realloc(p, n)` 错在哪？
3. 四类内存错误各举一例。

**验收标准**：

- [ ] 能画出进程内存布局，并指出任意变量落在哪一段
- [ ] `ex2` 扩容正确，`realloc` 用临时变量
- [ ] 能说出「所有权」在 `dup_string` 与 `free_list` 里分别是什么

## Day 6：二进制与位运算

**学习目标**：为 15-213 的 Bits/Bytes/Integers 做准备。

**读**：[06-二进制与位运算](06-二进制与位运算.md)。

**做**：

| 练习 | 要求 |
| --- | --- |
| `ex1_bases.c` | 同一数的四种进制输出 |
| `ex2_masks.c` | `set_bit` / `clear_bit` / `toggle_bit` / `test_bit` |
| `ex3_twos_complement.c` | 验证 `-x == ~x + 1`，含 `INT_MIN` |
| `ex4_overflow.c` | 无符号回绕与有符号 UB，写溢出检测 |

**自测**：

1. `-1` 的 32 位补码是什么？
2. `int8_t a = -1; int32_t b = a;` 后 `b` 是多少？
3. `1 << 31` 为什么危险？

**验收标准**：

- [ ] 能手算任意小整数的补码与十六进制
- [ ] 掩码四个函数全部正确
- [ ] 能解释符号扩展与算术/逻辑右移的区别

## Day 7：编译、链接与调试

**学习目标**：理解四阶段，能用 GDB 与 Valgrind。

**读**：[08-编译与链接](08-编译与链接.md)、[09-GDB与Valgrind](09-GDB与Valgrind.md)。

**做**：

| 练习 | 要求 |
| --- | --- |
| `multi/` | `main.c` + `util.c` + `util.h` + `Makefile` |
| `ex5_macro.c` | 验证宏参数括号的重要性 |
| `ex6_undefined.c` | 制造 `undefined reference`，用 `nm` 定位 |
| `ex7_gdb_crash.c` | 空指针崩溃，用 GDB 找行号 |
| `ex8_valgrind_leak.c` | 泄漏，用 Valgrind 定位 |
| `ex9_asan_overflow.c` | 越界，用 ASan 定位 |
| `ex10_backtrace.c` | 三层调用，用 `backtrace` 找源头 |

**自测**：

1. 四个阶段各产生什么文件？
2. `undefined reference` 与 `multiple definition` 的原因？
3. `definitely lost` 与 `still reachable` 的区别？

**验收标准**：

- [ ] `make` 能一次构建多文件项目
- [ ] 能用 `nm` 判断符号已定义/未定义
- [ ] 能用 GDB 在崩溃处 `backtrace` 并读出出错行
- [ ] 若本机未装 gdb/valgrind，**记录为「未执行」而不是「通过」**

## 时间不够时怎么砍

| 优先级 | 内容 | 理由 |
| --- | --- | --- |
| 必须 | Day 3 指针、Day 5 内存、Day 6 位运算 | 15-213 直接依赖 |
| 重要 | Day 2 数组字符串、Day 8 综合项目 | 写代码的基本功 |
| 可压缩 | Day 1 基础语法 | 你以前接触过 C，可快速过 |
| 可推迟 | Day 4 链表细节、Day 7 GDB 高级命令 | 进 15-213 后再补 |

**唯一不能跳的是 Day 3 与 Day 5。**

## 每天结束时的三个问题

1. 今天哪一段我是**背下来**的，而不是**推出来**的？
2. 哪个练习我是「看起来跑通了」而不是「测试断言通过」？
3. 明天的内容依赖今天的哪一部分？
