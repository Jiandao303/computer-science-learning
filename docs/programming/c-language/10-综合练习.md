## 通俗类比

写这个项目像组装一台小机器：头文件是接口面板（插孔长什么样），`.c` 是内部齿轮，`Makefile` 是装配说明书，测试是出厂检验。**任何一个齿轮装错，出厂检验都会亮红灯。**

## 原理讲解

### 为什么先写头文件

头文件是**契约**：

1. 主程序只需要知道「函数长什么样」，不需要知道实现。
2. 多个 `.c` 可以并行开发，只要接口不变。
3. 改实现不改接口，调用方不用重编（概念上）。

**顺序**：`头文件 → 实现 → 主程序 → 测试`。反过来写，接口会被实现细节牵着走。

### 错误处理策略

| 场景 | 策略 |
| --- | --- |
| 函数参数非法（`NULL`、`n == 0`） | 返回错误码，不崩溃 |
| 内存分配失败 | 返回错误码，调用者负责清理 |
| 用户输入非法 | 打印到 `stderr`，返回非 0 退出码 |

**本项目约定**：所有返回 `int` 的「动作函数」返回 0 表示成功、非 0 表示失败。

## 代码示例

```c
/* src/array_ops.c */
#include "array_ops.h"

int array_sum(const int *a, size_t n) {
    if (a == NULL) return 0;
    int s = 0;
    for (size_t i = 0; i < n; i++) s += a[i];
    return s;
}

int array_max(const int *a, size_t n, int *out) {
    if (a == NULL || out == NULL || n == 0) return -1;
    int best = a[0];
    for (size_t i = 1; i < n; i++) {
        if (a[i] > best) best = a[i];
    }
    *out = best;
    return 0;
}
```

```c
/* src/bit_ops.c */
#include <stdio.h>
#include "bit_ops.h"

void print_bits(unsigned x) {
    for (int i = 31; i >= 0; i--) {
        putchar(((x >> i) & 1u) ? '1' : '0');
        if (i % 4 == 0 && i != 0) putchar(' ');
    }
    putchar('\n');
}

int bit_test(unsigned x, int pos) {
    return (pos >= 0 && pos < 32) ? (int)((x >> pos) & 1u) : -1;
}

unsigned bit_set(unsigned x, int pos)   { return x | (1u << pos); }
unsigned bit_clear(unsigned x, int pos) { return x & ~(1u << pos); }
```

```c
/* src/str_ops.c */
#include <string.h>
#include "str_ops.h"

void reverse_in_place(char *s) {
    if (s == NULL) return;
    size_t n = strlen(s);
    for (size_t i = 0; i < n / 2; i++) {
        char t = s[i];
        s[i] = s[n - 1 - i];
        s[n - 1 - i] = t;
    }
}

void swap_int(int *a, int *b) {
    if (a == NULL || b == NULL) return;
    int t = *a;
    *a = *b;
    *b = t;
}
```

```c
/* src/person.c */
#include <stdlib.h>
#include "person.h"

int person_cmp_age(const void *a, const void *b) {
    const Person *x = a;
    const Person *y = b;
    return (x->age > y->age) - (x->age < y->age);
}

void person_sort(Person *people, size_t n) {
    if (people == NULL || n < 2) return;
    qsort(people, n, sizeof *people, person_cmp_age);
}
```

```c
/* src/main.c（节选） */
#include <stdio.h>
#include <string.h>
#include <stdlib.h>
#include "array_ops.h"
#include "bit_ops.h"
#include "str_ops.h"
#include "person.h"

static void cmd_dyn(void) {
    size_t cap = 2, len = 0;
    int *v = malloc(cap * sizeof *v);
    if (v == NULL) { fprintf(stderr, "oom\n"); return; }
    for (int i = 0; i < 10; i++) {
        if (len == cap) {
            size_t nc = cap * 2;
            int *tmp = realloc(v, nc * sizeof *v);
            if (tmp == NULL) { free(v); fprintf(stderr, "oom\n"); return; }
            v = tmp; cap = nc;
        }
        v[len++] = i * i;
    }
    for (size_t i = 0; i < len; i++) printf("%d ", v[i]);
    printf("\nlen=%zu cap=%zu\n", len, cap);
    free(v);
}

int main(int argc, char **argv) {
    if (argc < 2) { fprintf(stderr, "usage: %s <cmd>\n", argv[0]); return 2; }
    const char *cmd = argv[1];

    if (strcmp(cmd, "sum") == 0) {
        int a[] = {1, 2, 3, 4, 5};
        printf("%d\n", array_sum(a, 5));
    } else if (strcmp(cmd, "bits") == 0) {
        print_bits(0x12345678u);
    } else if (strcmp(cmd, "dyn") == 0) {
        cmd_dyn();
    } else if (strcmp(cmd, "--help") == 0) {
        printf("cmds: sum max reverse swap bits bitset bitclear bittest dyn people\n");
    } else {
        fprintf(stderr, "unknown cmd: %s\n", cmd);
        return 2;
    }
    return 0;
}
```

```makefile
# Makefile
CC      = gcc
CFLAGS  = -std=c11 -Wall -Wextra -Wpedantic -g -O0 -Iinclude
TARGET  = memtool
SRCS    = src/main.c src/array_ops.c src/bit_ops.c src/str_ops.c src/person.c
OBJS    = $(SRCS:.c=.o)

$(TARGET): $(OBJS)
	$(CC) $(CFLAGS) -o $@ $(OBJS)

%.o: %.c
	$(CC) $(CFLAGS) -c $< -o $@

test: $(TARGET)
	bash tests/run_tests.sh

clean:
	rm -f $(OBJS) $(TARGET)

.PHONY: test clean
```

## 逐行代码解释

| 片段 | 说明 |
| --- | --- |
| `if (a == NULL) return 0;` | 参数检查：不崩溃，返回合理默认值 |
| `if (n == 0) return -1;` | 空数组无法求最大值，返回错误码 |
| `(x >> i) & 1u` | 逐位取出，从最高位开始打印 |
| `x & ~(1u << pos)` | 清位：先造掩码再取反 |
| `strlen(s)` + 双指针交换 | 原地反转，O(n) 时间 O(1) 空间 |
| `realloc` 用 `tmp` 接收 | 失败时不丢失原指针 |
| `free(v)` 在 `cmd_dyn` 末尾 | 每个 `malloc` 配一个 `free` |
| `strcmp(cmd, "sum") == 0` | 字符串比较必须用 `strcmp` |

## 常见错误

| 错误 | 后果 | 正确做法 |
| --- | --- | --- |
| 头文件里写实现 | 重复定义 | 只放声明 |
| 忘记 `-Iinclude` | 找不到头文件 | Makefile 加 `-Iinclude` |
| `cmd_dyn` 忘记 `free` | 泄漏 | 每条返回路径都释放 |
| `realloc` 直接赋给 `v` | 失败时泄漏 | 用 `tmp` |
| `reverse` 用 `n/2` 写成 `n` | 反转两次等于没反转 | `i < n / 2` |
| 用 `==` 比较字符串 | 比较地址 | `strcmp` |

## 边界情况

- **空数组**：`array_max` 返回错误码。
- **空字符串**：`reverse_in_place("")` 不应越界。
- **`NULL` 指针**：所有公开函数都要处理。
- **`argc == 1`**：打印用法并返回非 0。
- **分配失败**：可在 `malloc` 前用环境变量模拟强制失败（练习用）。
