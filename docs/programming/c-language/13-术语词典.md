# 13 术语词典

> 全库统一译名。同一术语在不同笔记里必须用同一个中文译名。
> 排序：按字母序。**英文术语必须保留**，中文只是辅助。

## A–D

| 英文 | 中文 | 一句话 |
| --- | --- | --- |
| address-of operator | 取地址运算符 | `&x`，得到对象地址 |
| alignment | 对齐 | 对象地址必须是其对齐要求的倍数 |
| arithmetic shift | 算术右移 | 右移时高位补符号位 |
| array decay | 数组退化 | 数组名在表达式中变成指向首元素的指针 |
| automatic storage | 自动存储期 | 局部变量，函数返回即失效 |
| bit mask | 位掩码 | 用 `&` / `\|` / `^` 选定位的模式 |
| buffer overflow | 缓冲区溢出 | 写入超出分配或声明的大小 |
| callback | 回调 | 把函数指针传给别的函数，由它调用 |
| call by value | 值传递 | 函数收到实参的副本（C 唯一的方式） |
| cast | 类型转换 | `(type)expr` |
| compilation unit | 编译单元 | 一个 `.c` 预处理后的全部内容 |
| const-correctness | const 正确性 | 用 `const` 表达「不修改」的意图 |
| dangling pointer | 悬空指针 | 指向已释放或已失效内存的指针 |
| dereference | 解引用 | 通过指针访问它指向的对象 |
| double free | 重复释放 | 对同一块内存 `free` 两次 |
| double pointer | 二级指针 | 指向指针的指针 |

## E–L

| 英文 | 中文 | 一句话 |
| --- | --- | --- |
| enum | 枚举 | 具名整数常量集合 |
| escape sequence | 转义序列 | `\n`、`\0`、`\\` 等 |
| external linkage | 外部链接 | 名字可跨文件使用 |
| fallthrough | 贯穿 | `switch` 中不写 `break` 继续执行下一 `case` |
| function pointer | 函数指针 | 存函数入口地址的变量 |
| heap | 堆 | `malloc` 管理的内存区 |
| include guard | 包含保护 | `#ifndef` / `#define` 防止头文件重复包含 |
| incomplete type | 不完整类型 | 只声明未定义的类型 |
| integer overflow | 整数溢出 | 结果超出可表示范围 |
| internal linkage | 内部链接 | `static` 修饰，仅本文件可见 |
| lazy deletion | 懒惰删除 | 堆中允许过期条目，弹出时丢弃 |
| linkage | 链接 | 名字能否跨文件使用 |
| logical shift | 逻辑右移 | 右移时高位补 0 |

## M–R

| 英文 | 中文 | 一句话 |
| --- | --- | --- |
| memory leak | 内存泄漏 | 分配后未释放，且已失去引用 |
| null pointer | 空指针 | 值为 `NULL` 的指针 |
| null terminator | 空字符终止符 | 字符串末尾的 `\0` |
| ownership | 所有权 | 谁负责释放这块内存 |
| padding | 填充 | 为对齐插入的无用字节 |
| pointer arithmetic | 指针算术 | `p + n` 按元素步长前进 |
| qualifier | 限定符 | `const` / `volatile` / `restrict` |
| realloc | 重新分配 | 改变已分配块大小，可能搬家 |
| redzone | 红区 | ASan 在分配块周围插入的保护区 |
| relocation | 重定位 | 链接时修正地址 |

## S–Z

| 英文 | 中文 | 一句话 |
| --- | --- | --- |
| segmentation fault | 段错误 | 访问不属于自己的内存页 |
| shared library | 动态库 | `.so`，运行时加载 |
| sign extension | 符号扩展 | 小类型转大类型时复制符号位 |
| stack frame | 栈帧 | 一次函数调用的栈上空间 |
| static library | 静态库 | `.a`，编译时复制进可执行文件 |
| storage duration | 存储期 | 对象活多久（自动/静态/动态） |
| strict aliasing | 严格别名 | 不同时用两种类型指针访问同一对象 |
| symbol table | 符号表 | 记录已定义与未定义符号 |
| translation unit | 编译单元 | 同 compilation unit |
| two's complement | 补码 | 负数 = 取反加一 |
| undefined behavior (UB) | 未定义行为 | 标准不规定结果，编译器可任意处理 |
| use-after-free | 释放后使用 | 访问已 `free` 的内存 |
| wild pointer | 野指针 | 未初始化的指针 |
| wraparound | 回绕 | 无符号溢出后的取模行为 |

## 使用规则

1. **首次出现**用「英文（中文）」格式，之后可只用中文。
2. 代码、注释、变量名一律用英文，不要用拼音。
3. 不要自创译名：本表没有的术语，先查 cppreference 或 GNU 手册的对应中文条目。
4. 本表与 `95-计算机术语词典/Computer-Science-Glossary.md` 冲突时，**以本表为准**（仅限 C 语言相关术语）。
