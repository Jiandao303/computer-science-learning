# 编程基础 · 领域总览

> **一句话**：把一个想法变成能跑、能调、能改的程序。

## 这个领域回答的问题

- 语言如何表达控制流与数据？
- 程序出错时如何定位？
- 如何建立第一层抽象？

## 边界：它不负责什么

不教具体框架与业务；不追求某门语言的全部语法特性；不涉及工程协作（见 90 软件工程）。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 无（本领域是入口） |
| **学完之后支撑** | 30 数据结构与算法、40 计算机组成 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
