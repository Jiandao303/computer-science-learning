# 算法设计范式

> 本篇为原创笔记，不逐页翻译任何讲义；课程与教材见 [02-权威课程与资料](02-权威课程与资料.md)。

## 一句话总结

算法设计范式解决的是「拿到一个新问题，先往哪个方向想」：分治把问题拆小，贪心每步取局部最优，动态规划记住重复子问题，回溯系统枚举并剪枝，随机化用随机性规避最坏情况。**先判断问题结构，再选范式，最后用正确性证明和复杂度分析兜底。**

## 核心概念

### 分治（Divide and Conquer）

把原问题分成若干**互不重叠**、规模更小的同类子问题，递归求解后把结果合并。三个关键点：

1. 子问题必须同类型、规模可缩小，否则递归不收敛。
2. 子问题之间独立；如果子问题大量重叠，应转向动态规划。
3. 合并步骤的代价要可控；合并太贵会吃掉递归带来的收益。

复杂度通常写成递归式，例如 `T(n) = aT(n/b) + f(n)`，再用主定理或递归树求解。

### 贪心（Greedy）

每一步都在当前信息下选「看起来最好」的候选，且**不撤销**。它不保证全局最优；能用贪心的结构通常有：

- **贪心选择性质**：存在一个最优解包含当前贪心选择。
- **最优子结构**：做出选择后，剩余问题的最优解能拼成原问题的最优解。

正确性常用**交换论证**（exchange argument）：假设最优解与贪心解不同，把最优解逐步替换成贪心选择，证明解不会变差。

### 动态规划（Dynamic Programming, DP）

把问题拆成**重叠子问题**，将子问题的解存表复用。四件套：

1. **状态定义**：`dp[i]` 或 `dp[i][j]` 具体表示什么，一句话能说清，且能覆盖所有子问题。
2. **转移方程**：当前状态由哪些更小状态推出。
3. **边界条件**：最小子问题的解。
4. **计算顺序**：保证用到的状态已经算过（自底向上），或递归 + 备忘录（自顶向下）。

DP 的本质是「不重复计算同一子问题的穷举」。状态定义错了，转移方程再漂亮也没用。

### 回溯（Backtracking）

把求解过程看成对**决策树**的深度优先搜索：每层做一个选择，进入下一层；发现当前选择不可能产生合法解时**剪枝**并回退。与普通 DFS 的区别在于：

- 回溯维护「当前部分解」和「已用资源」，需要显式撤销选择。
- 剪枝函数（可行性剪枝、最优性剪枝）决定它是否比暴力枚举快。

### 随机化（Randomization）

算法执行过程中使用随机数。两类：

- **Las Vegas**：结果一定正确，运行时间随机（如随机快排、随机快速选择）。
- **Monte Carlo**：运行时间有界，结果以一定概率出错（如 Miller–Rabin 素性测试、哈希碰撞概率分析）。

随机化的价值不是「让算法变简单」，而是**让最坏输入不再由对手决定**。

## 推导 / 例子

### 例子一：归并排序（分治）

伪代码（非官方，仅用于说明）：

```text
mergeSort(A, l, r):
    if l >= r: return
    m = (l + r) / 2
    mergeSort(A, l, m)
    mergeSort(A, m+1, r)
    merge(A, l, m, r)      # 合并两个有序段
```

`merge` 用两个指针扫描，时间与两段长度之和成正比，即 `Θ(n)`。
递归式：`T(n) = 2T(n/2) + Θ(n)`。主定理第二种情形（`f(n) = Θ(n^{log_2 2}) = Θ(n)`）给出 `T(n) = Θ(n log n)`。

**关键不是背结论，而是能写出递归式**：分了几份（a）、每份多大（n/b）、合并多贵（f(n)）。

### 例子二：区间调度（贪心 + 交换论证）

问题：给一组区间 `[s_i, f_i)`，选最多互不重叠的区间。
贪心策略：**按结束时间从早到晚排序，能选就选**。

为什么正确（交换论证的骨架）：

1. 设贪心选的第一个区间是 `g`，它结束最早。
2. 任取一个最优解 `O`，把 `O` 中第一个区间换成 `g`。因为 `g` 结束不晚于 `O` 的第一个区间，替换后不会与后面的区间冲突，解的大小不变。
3. 对剩余部分重复同样的论证，逐步把最优解变成贪心解。

**注意**：按开始时间、按区间长度排序都不能保证最优；贪心策略的正确性必须证明，不能靠直觉。

### 例子三：0-1 背包（动态规划）

问题：`n` 件物品，重量 `w_i`、价值 `v_i`，背包容量 `W`，每件最多选一次，求最大价值。

状态：`dp[i][w]` = 只考虑前 `i` 件物品、容量为 `w` 时的最大价值。
转移：

```text
dp[i][w] = max(dp[i-1][w], dp[i-1][w-w_i] + v_i)   # 后者要求 w >= w_i
```

边界：`dp[0][w] = 0`。
顺序：`i` 从 1 到 `n`，`w` 从 0 到 `W`。
答案：`dp[n][W]`。时间 `O(nW)`，空间 `O(nW)`；用滚动数组可降到 `O(W)`，但**内层容量必须倒序**，否则同一件物品会被重复选。

**这是伪多项式时间**：`O(nW)` 看起来是多项式，但 `W` 是数值大小，输入长度只有 `log W` 位。

对比：如果每件物品可以选无限次（完全背包），内层容量改为正序即可。

### 例子四：N 皇后（回溯 + 剪枝）

在 `n×n` 棋盘放 `n` 个皇后，任意两个不同行、不同列、不同对角线。

决策树：第 `i` 行放在哪一列。逐行放置，维护三个集合：

- `cols`：已占用的列；
- `diag1`：已占用的主对角线（`row - col` 为常数）；
- `diag2`：已占用的副对角线（`row + col` 为常数）。

伪代码：

```text
solve(row):
    if row == n: 记录一个解; return
    for col in 0..n-1:
        if col in cols or (row-col) in diag1 or (row+col) in diag2: continue
        放入皇后，更新三个集合
        solve(row+1)
        撤销皇后，恢复三个集合
```

剪枝发生在「当前列/对角线已被占用」时：不进入下一层，直接换下一个 `col`。最坏复杂度仍是 `O(n!)`，但剪枝让实际搜索量远小于全排列。

### 例子五：随机快排与随机快速选择（随机化）

普通快排在输入已经有序、且固定选第一个元素作 pivot 时退化为 `O(n²)`。随机选 pivot 后：

- 对**任意**输入，期望比较次数是 `O(n log n)`；
- 最坏情况仍可能发生，但概率极低，且不再由输入顺序决定。

随机快速选择（quickselect）同理：每次随机选 pivot，只递归包含第 `k` 小元素的那一侧，期望 `O(n)`，最坏 `O(n²)`。

另一个常用例子是**蓄水池抽样**：从长度未知的数据流中等概率选出 `k` 个元素。处理第 `i` 个元素时，以 `k/i` 的概率保留它，并随机替换掉池中的一个。可以用归纳法证明每个元素最终被选中的概率都是 `k/n`。

## 容易混淆的概念

| 对比 | 分治 | 动态规划 |
| --- | --- | --- |
| 子问题关系 | 互不重叠 | 重叠，需要记忆化 |
| 典型例子 | 归并排序、二分查找 | 背包、编辑距离、LIS |
| 复杂度来源 | 递归式 + 合并代价 | 状态数 × 每个状态的转移代价 |

| 对比 | 贪心 | 动态规划 |
| --- | --- | --- |
| 选择方式 | 每步选局部最优，不回头 | 保留所有可能状态，最后取全局最优 |
| 正确性 | 需要交换论证/结构性质 | 需要最优子结构 + 无后效性 |
| 反例 | 0-1 背包按性价比贪心会错 | —— |

| 对比 | 回溯 | 普通 DFS |
| --- | --- | --- |
| 目标 | 找所有解/一个可行解 | 遍历图或树 |
| 关键操作 | 选择、剪枝、撤销 | 访问标记 |
| 复杂度 | 解空间大小，剪枝后可能小很多 | 顶点数 + 边数 |

## 没懂的地方

- 主定理三种情形的完整条件，尤其第三种情形的「正则条件」，我只记住了结论，还没有手推过。**待核实**。
- 交换论证的严谨写法：什么时候可以「逐步替换」，什么时候只能「一次性替换」，还需要更多例题。
- 随机化算法的期望分析：指示器随机变量的线性性会用，但遇到「随机变量之间有依赖」时容易卡住。
- 回溯的复杂度紧界：剪枝后的搜索树大小如何估计，目前只会说「最坏 O(n!)」。

## 自测

1. 写出归并排序的递归式，并用主定理求出复杂度。如果改成「分成 3 份、每份 n/3、合并 O(n)」，复杂度是多少？
2. 区间调度为什么按结束时间排序是正确的？给出交换论证的三个关键步骤。
3. 0-1 背包的滚动数组为什么必须倒序遍历容量？如果正序会发生什么？
4. 完全背包和 0-1 背包的转移方程只差一个下标，具体差在哪里？
5. N 皇后的三个集合分别记录什么？为什么用 `row-col` 和 `row+col` 就能表示两条对角线？
6. 随机快排的「期望 O(n log n)」和「最坏 O(n²)」矛盾吗？Las Vegas 和 Monte Carlo 的区别是什么？

<details>
<summary>参考答案（先自己做，再看）</summary>

1. `T(n)=2T(n/2)+Θ(n)=Θ(n log n)`；三分版本 `T(n)=3T(n/3)+Θ(n)=Θ(n log n)`（主定理第二种情形，`log_3 3 = 1`）。
2. 结束最早留下最多空间；交换论证：替换第一个区间不减少兼容性 → 逐步替换 → 贪心解不劣于最优解。
3. 倒序保证 `dp[w-w_i]` 仍是「上一行」的值；正序会让同一件物品在本轮被重复使用，变成完全背包。
4. 0-1 背包用 `dp[i-1][w-w_i]`；完全背包用 `dp[i][w-w_i]`（允许同一物品再次出现）。
5. `cols` 记录列；`row-col` 相同表示同一条主对角线；`row+col` 相同表示同一条副对角线。
6. 不矛盾：期望是平均意义，最坏是极端输入；Las Vegas 结果必对、时间随机，Monte Carlo 时间有界、结果可能错。

</details>
