# 数据结构与算法 · 领域总览

> **一句话**：回答「什么样的数据组织与求解策略，是足够快的」。

## 这个领域回答的问题

- 如何衡量一个算法的代价？
- 哪种数据结构让目标操作最便宜？
- 面对新问题该用哪种设计范式？

## 边界：它不负责什么

不做竞赛技巧的穷举；不替代具体系统的工程优化（见 40/50/70）。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 20 编程基础（函数、递归、指针/引用）、10 数学基础（归纳、计数、渐进） |
| **学完之后支撑** | 40 计算机组成、80 编译原理、160 计算机高级选修 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
