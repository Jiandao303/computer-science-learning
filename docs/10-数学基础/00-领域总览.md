# 数学基础 · 领域总览

> **一句话**：为计算机科学提供三样工具：证明、计数、概率。

## 这个领域回答的问题

- 一个命题怎样才算被证明？
- 算法的代价如何用数学界定？
- 随机性如何建模并推出结论？

## 边界：它不负责什么

不做数学分析、实变函数、泛函分析的深度训练；不替代数值计算与最优化专门课程。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 高中代数与基础微积分直觉 |
| **学完之后支撑** | 30 数据结构与算法、160 计算机高级选修 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
