**这是四个已有内容领域里覆盖率最低的一块，但原因很具体：15-214 是「面向对象设计课」，不是「工程实践课」。**

它讲的是「怎么设计出好代码」——设计原则、设计模式、规格说明、测试思想、并发、静态分析。
它不讲「怎么把一个团队的工作流跑起来」——版本控制、代码评审、CI/CD、构建工具、发布流程。

所以 **17 个空缺里，有 13 个是这门课本来就不讲的**，不是笔记漏了。剩下 4 个（提取函数/类、消除重复、遗留代码的接缝、CI 门禁）属于「课程提到但没展开」。

## 建议的补课顺序

这门课的空缺**不是靠读笔记能补的**，必须动手：

1. **分支策略 + 代码评审 + 提交信息** —— 在一个真实仓库里练。这是所有工程岗位的日常，15-214 完全不讲
2. **构建系统 + 依赖冲突** —— 用 Gradle 或 Maven 从零搭一个 Java 项目，故意引入一次版本冲突再解决
3. **重构手法** —— 读 Fowler《重构》的坏味道目录，在自己的代码上改三处
4. **测试替身 + 覆盖率局限** —— 用 JUnit 5 + Mockito + JaCoCo 重做一遍 15-214 的测试练习，体会 2013 到现在的工具演进
5. **CI 门禁** —— 本仓库已有 `.github/workflows/` 目录，是练手的好地方

## 关于学期

**15-214 用的是 Fall 2013 版本**，这是硬性约束（见 `sources/02-来源登记表.md` 的 S-003）。

**过时的部分**：Java 7、JUnit 4 语法、Swing GUI、Ant 构建、早期 Mockito。
**不过时的部分**：设计原则、设计模式、规格说明、并发模型、静态分析思想、类型状态。

看笔记时注意区分这两类。凡是涉及具体工具和 API 的段落，都要用现代版本重新验证一遍。
