# 计算机网络 · 领域总览

> **一句话**：两台机器之间如何可靠地把字节送过去。

## 这个领域回答的问题

- 一个包从浏览器到服务器经过哪些层？
- TCP 为什么需要三次握手？
- 网络卡顿时该调什么？

## 边界：它不负责什么

不深入无线/光传输物理层；不替代分布式系统的一致性讨论。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 50 操作系统（socket、缓冲、阻塞） |
| **学完之后支撑** | 100 前端开发、110 后端开发、120 软件安全 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
