# 编译原理 · 领域总览

> **一句话**：文本如何变成可执行的语义。

## 这个领域回答的问题

- 一段源码怎样被切成 token？
- 语法树如何构造？
- 优化器凭什么敢改你的代码？

## 边界：它不负责什么

不追求某语言完整前端实现；不替代程序语言理论（见 160）。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 30 数据结构与算法（树、图、哈希）、40 计算机组成（寄存器、指令） |
| **学完之后支撑** | 90 软件工程、160 计算机高级选修 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
