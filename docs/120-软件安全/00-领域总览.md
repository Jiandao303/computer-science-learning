# 软件安全 · 领域总览

> **一句话**：对手存在时，系统如何仍然正确。

## 这个领域回答的问题

- 攻击者会从哪里进来？
- 这个输入为什么能变成代码执行？
- 如何证明我没漏掉一整类漏洞？

## 边界：它不负责什么

不做渗透测试的社工与物理入侵；不替代合规审计。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 40 计算机组成、50 操作系统、60 计算机网络 |
| **学完之后支撑** | 130 DevOps与运维 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
