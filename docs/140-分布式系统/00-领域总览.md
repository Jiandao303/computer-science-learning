# 分布式系统 · 领域总览

> **一句话**：多台机器如何表现得像一台。

## 这个领域回答的问题

- 网络分区时，系统该牺牲什么？
- 两个节点如何就一个值达成一致？
- 为什么「最终一致」经常不最终？

## 边界：它不负责什么

不做特定中间件的运维调参；不替代共识算法的形式化证明。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 50 操作系统、60 计算机网络、70 数据库 |
| **学完之后支撑** | 150 系统架构 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
