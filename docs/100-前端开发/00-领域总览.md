# 前端开发 · 领域总览

> **一句话**：界面如何被构建、渲染、交互。

## 这个领域回答的问题

- 浏览器从收到 HTML 到画出像素做了什么？
- 状态变了界面为什么没更新？
- 首屏为什么慢？

## 边界：它不负责什么

不深入某框架内部源码；不替代视觉设计与交互设计。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 20 编程基础、60 计算机网络（HTTP、缓存、CORS） |
| **学完之后支撑** | 120 软件安全、150 系统架构 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
