# 计算机高级选修 · 领域总览

> **一句话**：在主干之上选一个专门方向深入。

## 这个领域回答的问题

- 我该往 AI、系统、图形还是 PL 走？
- 这个方向的前置到底缺什么？
- 如何判断一门课值不值得投入三个月？

## 边界：它不负责什么

本领域是方向索引，不为每个方向提供完整知识点清单；选定方向后应另建子目录。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 10 数学基础、30 数据结构与算法 |
| **学完之后支撑** | 150 系统架构 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
