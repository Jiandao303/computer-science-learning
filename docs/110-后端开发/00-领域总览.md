# 后端开发 · 领域总览

> **一句话**：服务如何承载业务、连接存储、对外提供 API。

## 这个领域回答的问题

- 一个请求在服务内部经过哪些环节？
- 并发上来后哪里先崩？
- 接口出错时如何让调用方正确处理？

## 边界：它不负责什么

不绑定某一语言生态；不替代数据库内核与分布式共识。

## 前置与后继

| | |
| --- | --- |
| **学之前最好已掌握** | 50 操作系统、60 计算机网络、70 数据库 |
| **学完之后支撑** | 120 软件安全、130 DevOps与运维、150 系统架构 |

## 学完应该能做到

1. 用本领域的术语准确描述一个具体问题，而不是用「感觉慢」「好像有问题」。
2. 拿到一个陌生系统，能判断它在本领域的哪一层、瓶颈可能在哪里。
3. 读得懂本领域的经典教材章节与官方文档，不需要先看二手解读。
