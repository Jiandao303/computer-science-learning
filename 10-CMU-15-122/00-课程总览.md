## 二、这门课到底在教什么

**一句话定位**：教你**在写代码之前就确信代码正确**，而不是写完再靠测试和调试去猜。

这不是一句口号。整门课围绕一条方法论展开：

```
先写契约（要什么、保证什么）
  → 再写循环不变式（每一步都成立的事实）
    → 用「逐点推理」证明每一步都安全、每个循环都终止
      → 最后才让代码通过编译器
```

**四个贯穿全课的关键词**（讲义反复回到这四点）：

| 关键词 | 含义 | 在哪几讲体现 |
|---|---|---|
| **Abstraction（抽象）** | 用接口隐藏实现；调用者只需知道契约，不需知道内部结构 | L08 库、L09–L13 数据结构、L21 图接口 |
| **Correctness（正确性）** | 程序对**所有**满足前置条件的输入都满足后置条件，而非「我试了几个例子都对」 | L01 契约、L05 复杂度、L26 不变量恢复 |
| **Complexity（复杂度）** | 用 Big-O 描述增长趋势，区分「能跑」和「跑得动」 | L05 Big-O、L06 二分、L07 快排、L16 AVL、L24 并查集 |
| **Modularity（模块化）** | 分离编译、头文件、信息隐藏、归属权（ownership） | L08 库、L17 分离编译、L18 内存模型 |

### 三个学习目标维度

讲义每讲开头都会列出它覆盖的目标类别，全课归为三类：

1. **Computational Thinking（计算思维）**：写出契约、做逐点推理、给出终止性论证、区分「规格」与「实现」。
2. **Algorithms and Data Structures（算法与数据结构）**：整数算法、搜索、排序、哈希、树、堆、图、并查集。
3. **Programming（编程）**：C0 与标准 C 的语法、内存管理、调试工具（valgrind、gdb）、代码风格。

## 三、语言分界：C0 与标准 C（**这是全课最重要的结构性事实**）

15-122 用**两种语言**。混淆它们是自学这门课最常见的错误。

| | 前九周（L01–L16） | 后五周（L17–L26） |
|---|---|---|
| 语言 | **C0**（CMU 自制的教学语言） | **标准 C**（C99） |
| 文件扩展名 | `.c0`（L14 起有 `.c1` 变体） | `.c` |
| 编译器 | `cc0`（另有一个解释器 `coin`） | `gcc` |
| 契约 | **语言的一部分**：`//@requires`、`//@ensures`、`//@loop_invariant`、`//@assert` 由 `cc0` 在运行时检查 | **只是注释**。要真检查必须用 `lib/contracts.h` 的 `REQUIRES` / `ENSURES` / `ASSERT` 宏，并加 `-DDEBUG` 编译 |
| 内存管理 | **自动**（有垃圾回收） | **手动**：`malloc` / `calloc` / `free`，配 `xmalloc` / `xcalloc` 包装 |
| 指针 | 有，但受限（`void*` 不能解引用，带 tag） | 完整指针算术，可指向任何对象，越界与悬空指针是未定义行为 |
| 数组 | 有 `\length()` 契约，越界会被捕获 | 无边界检查；越界是未定义行为（undefined behavior） |
| 整数溢出 | **定义为模运算**（回绕） | **未定义行为**（有符号溢出），可用 `unsigned` 或 `-fwrapv` 规避 |
| 字符串 | `string` 是内建类型，`<conio>` 提供输入输出 | `char*` + `<string.h>` + `<stdio.h>` |
| 头文件 | `#use <conio>` 等 | `#include <stdio.h>` + 自己写 include guard |
| 调试工具 | `coin` 的运行时检查、`cc0 -d` | **valgrind**、gdb、`-fsanitize` |

**为什么这样设计**：先用一门「会帮你抓错」的语言教会你契约思维，再把你扔进「什么都不帮你抓」的标准 C。第 17 讲讲义原话的意思是：**在 C 里，契约不会自动生效，你必须自己承担**。这个落差是课程设计的一部分，不是缺陷。

**笔记中的标注规则**：凡涉及 `//@` 注解、`coin`/`cc0`、整数回绕、`->` 指针语法，笔记里必须明示「这是 C0」或「这是标准 C」。第 17 讲起每篇笔记的第 2 节都有一张 C0 vs C 对照表。

## 四、评分构成

满分 **1000 分**，公式：

```
总分 = min(PR + PG, CH) + AC + FI
```

| 代号 | 含义 | 满分 | 计入上限 | 说明 |
|---|---|---|---|---|
| **PR** | Participation / Review（参与与复习） | 120 | — | 课堂参与、复习测验等 |
| **PG** | Programming（编程作业） | 600 | — | 约 10 次编程作业，通过 Autolab 提交 |
| **CH** | Checkpoints / 考试（期中类） | 780 | **720** | 多次考核累计，但最多计入 720 |
| **AC** | Activities（活动） | 39 | **30** | 课堂活动、小测等 |
| **FI** | Final Exam（期末考试） | 250 | — | 期末考试 |

**这个公式的设计意图**：

- `min(PR + PG, CH)` 把「平时分」和「考试分」**取较小值**。也就是说，**只靠作业刷分是没用的**——如果考试考不到，平时分再高也被 CH 卡住；反过来只考得好而作业不交，也会被 PR+PG 卡住。**两边都得做。**
- `PR + PG` 上限 720（120 + 600），`CH` 计入上限也是 720。**两条路径通向同一个上限**，这是刻意的平衡。
- `AC` 上限 30 而满分 39，意味着**活动分允许丢 9 分**，不必追满。
- 验证：`720 + 30 + 250 = 1000` ✓。

> 待核实：具体的作业次数、考试次数与各次权重未在公开讲义中给出，需查课程 syllabus（本库未收录）。以上构成来自课程公开页面的评分公式说明。

## 五、26 讲的整体脉络

课程分五个阶段，每个阶段解决一类问题：

### 阶段一：基础（L01–L04）

- **L01 契约（Contracts）**：前置条件、后置条件、循环不变量、断言、逐点推理。整门课的方法论地基。
- **L02 整数（Ints）**：二进制、补码、位运算、整数溢出在 C0 中的模语义。
- **L03 数组（Arrays）**：一维/二维数组、`\length()`、数组契约、别名。
- **L04 搜索（Search）**：线性搜索、正确性证明、循环不变式的第一个实战。

### 阶段二：算法入门（L05–L08）

- **L05 排序与 Big-O**：插入排序、选择排序、渐近复杂度、O/Ω/Θ。
- **L06 二分搜索（Binary Search）**：有序数组、`O(log n)`、不变式的精确表述（最容易写错边界的算法）。
- **L07 快速排序（Quicksort）**：分治、划分、期望 `O(n log n)`、最坏 `O(n²)`。
- **L08 数据结构与库（Libraries）**：抽象数据类型、接口与实现分离、`#use` 机制。

### 阶段三：数据结构（L09–L16）

- **L09 栈与队列**：LIFO/FIFO、数组实现与链表实现。
- **L10 链表（Linked Lists）**：单链表、双链表、哨兵节点、迭代与递归。
- **L11 无界数组（Unbounded Arrays）**：动态扩容、摊还分析（amortized analysis）。
- **L12 哈希表（Hash Tables）**：哈希函数、冲突处理、负载因子。
- **L13 哈希字典（Hash Dictionaries）**：把哈希表包装成字典接口。
- **L14 泛型（Genericity）**：`void*`、函数指针、C1、五段内存模型。**C0 的能力上限。**
- **L15 二叉搜索树（BST）**：有序不变式、查找/插入、退化成链表。
- **L16 AVL 树**：高度不变式、旋转、`O(log n)` 保证。

### 阶段四：C 与机器（L17–L20）

- **L17 C 入门**：**语言分界点**。预处理器、宏、`malloc`/`free`、分离编译、valgrind。
- **L18 C 的内存模型**：五段布局、数组与指针算术、未定义行为、栈与堆。
- **L19 C 的类型**：整数类型族、`<stdint.h>`、类型转换、浮点、`union`/`enum`。
- **L20 C0 虚拟机（C0VM）**：把程序当数据看。栈机、字节码、常量池、函数调用、字节码验证。

### 阶段五：图与不变量（L21–L26）

- **L21 图的表示**：邻接矩阵 vs 邻接表、接口设计、复杂度对比。
- **L22 图搜索**：DFS、BFS、显式栈/队列、三条正确性不变式、最短路径。
- **L23 生成树**：树的六种等价刻画、边中心 vs 顶点中心算法、MST、Cycle Property、Kruskal、Prim。
- **L24 并查集（Union-Find）**：等价类、按高度合并、路径压缩、Ackermann 反函数。
- **L25 优先队列**：四种实现对比、最小堆的两条不变式、sift up/down、数组表示。
- **L26 恢复不变量**：标准 C 重写堆、部分不变式、`grandparent_check`、完整正确性证明、heapsort。

## 六、学完之后能做什么

15-122 是 CMU 计算机核心课的**第一门**。它的直接后继：

| 后续课程 | 依赖 15-122 的什么 |
|---|---|
| **15-213 计算机系统导论** | C 语言、指针、内存模型、未定义行为、valgrind——后五周的内容几乎是为 213 铺路 |
| **15-210 并行与串行数据结构与算法** | Big-O、摊还分析、BST/AVL/堆/并查集、图算法 |
| **15-214 软件设计** | 契约式设计（contract-based design）、抽象与模块化、测试 |

**更长远的能力**：

1. 看到一个循环，能写出它的不变式并证明它终止。
2. 看到一个数据结构，能判断它的操作复杂度，并说出为什么不能更快。
3. 看到一段 C 代码，能指出哪里可能越界、泄漏、悬垂、溢出。
4. 写代码时先想「规格」再想「实现」，而不是先写再调。
