# CMU 15-122 · 学习进度

> 课程入口见 [[10-CMU-15-122/00-课程总览|CMU 15-122 - 课程总览]]，讲次索引见 [[10-CMU-15-122/01-课程目录|CMU 15-122 - 课程目录]]。
> 勾选方式：读完一讲的笔记 + 讲义 + 做完讲义末尾习题后打勾。**「读完」不等于「学会」——习题是唯一的检验标准。**

---

## 一、总体安排

CMU 一个学期约 **15 周**，15-122 每周 2 次课（每次 80 分钟），26 讲正好铺满。本库的建议节奏：

| 阶段 | 讲次 | 周次 | 建议总学时 | 主题 |
|---|---|---|---|---|
| **阶段一：基础** | L01–L04 | 第 1–2 周 | 16 h | 契约、整数、数组、搜索 |
| **阶段二：算法入门** | L05–L08 | 第 3–5 周 | 22 h | 排序、Big-O、二分、快排、库与抽象 |
| **阶段三：数据结构** | L09–L16 | 第 6–9 周 | 44 h | 栈队列、链表、无界数组、哈希、BST、AVL、泛型 |
| **阶段四：C 与机器** | L17–L20 | 第 10–12 周 | 30 h | 标准 C、内存模型、类型、C0VM |
| **阶段五：图与不变量** | L21–L26 | 第 13–15 周 | 36 h | 图表示、DFS/BFS、生成树、并查集、堆 |

**总计约 148 小时**（不含作业）。这是「读懂 + 做完习题」的净学习时间，不含写代码作业。

> **如果时间紧**：阶段一、二不能跳（契约与 Big-O 是后面所有内容的地基）；阶段三的 L11–L13 可以先略读（无界数组、哈希表、哈希字典的细节在 L21 之后很少再用）；阶段五的 L23–L26 是整门课的高峰，**不能略读**。

## 二、26 讲逐讲 checklist

每讲的「建议学时」包含：读讲义 PDF（约 1 页 ≈ 3 分钟）+ 读中文笔记 + 做讲义末尾习题。

### 阶段一：基础（L01–L04）

- [ ] **L01 Contracts 契约** —— 建议 5 h
  - 核心：前置/后置条件、循环不变式、断言、逐点推理、终止性论证
  - 习题：讲义 p33–35 的 Ex1–Ex4（sample solutions 在 p36–39）
  - 笔记：[[15-122-01-Contracts]]
  - **检验**：能独立完成 Ex3（GCD 暴力版）的 INIT / PRES / EXIT / TERM 四步证明

- [ ] **L02 Ints 整数** —— 建议 4 h
  - 核心：二进制、补码、位运算、C0 中的模运算语义
  - 笔记：[[15-122-02-Ints]]
  - **检验**：能手算 `-15122` 的 32 位补码表示，并说明 `x << 1` 在 C0 与 C 中的不同

- [ ] **L03 Arrays 数组** —— 建议 3 h
  - 核心：一维/二维数组、`\length()`、数组契约、别名（aliasing）
  - 笔记：[[15-122-03-Arrays]]
  - **检验**：能写出「数组已排序」这个谓词的 C0 代码

- [ ] **L04 Search 搜索** —— 建议 4 h
  - 核心：线性搜索、循环不变式的第一个实战、返回下标的契约
  - 笔记：[[15-122-04-Searching-Arrays]]
  - **检验**：能证明「循环结束时若没找到，则目标不在数组中」

### 阶段二：算法入门（L05–L08）

- [ ] **L05 Sorting & Big-O 排序与复杂度** —— 建议 6 h
  - 核心：插入排序、选择排序、O/Ω/Θ 定义与运算、增长速率对比
  - 笔记：[[15-122-05-Big-O]]
  - **检验**：能判断 `3n² + 100n + 7` 是 Θ(n²)，并解释为什么常数项不影响

- [ ] **L06 Binary Search 二分搜索** —— 建议 6 h
  - 核心：有序前提、`O(log n)`、**边界条件的精确表述**（本讲最容易写错）
  - 笔记：[[15-122-06-Binary-Search]]
  - **检验**：能写出三种不同写法的二分（闭区间/半开区间）并说明各自的循环不变式

- [ ] **L07 Quicksort 快速排序** —— 建议 6 h
  - 核心：分治、划分（partition）、期望 `O(n log n)`、最坏 `O(n²)`、原地排序
  - 笔记：[[15-122-07-Quicksort]]
  - **检验**：能解释为什么「已排序输入 + 取首元素为枢轴」会退化

- [ ] **L08 Data Structures 数据结构与库** —— 建议 4 h
  - 核心：抽象数据类型、接口与实现分离、`#use` 机制、信息隐藏
  - 笔记：[[15-122-08-Libraries]]
  - **检验**：能说清「为什么调用者不该看到 `struct` 的定义」

### 阶段三：数据结构（L09–L16）

- [ ] **L09 Stacks and Queues 栈与队列** —— 建议 4 h
  - 核心：LIFO / FIFO、数组实现与链表实现、接口契约
  - 讲义：`90-原始PDF/15-122/lectures/09-stackqueue.pdf`（19 页）
  - 笔记：[[15-122-09-Stacks-and-Queues]]
  - **检验**：能说出队列用数组实现时为什么需要「循环数组」

- [ ] **L10 Linked Lists 链表** —— 建议 5 h
  - 核心：单链表、双链表、哨兵节点（sentinel）、迭代与递归
  - 讲义：`90-原始PDF/15-122/lectures/10-linkedlist.pdf`（30 页）
  - 笔记：[[15-122-10-Linked-Lists]]
  - **检验**：能写出「反转单链表」的迭代版与递归版，并证明两者等价

- [ ] **L11 Unbounded Arrays 无界数组** —— 建议 5 h
  - 核心：动态扩容、倍增策略、**摊还分析**（amortized analysis）
  - 讲义：`90-原始PDF/15-122/lectures/11-uba.pdf`（19 页）
  - 笔记：[[15-122-11-Unbounded-Arrays]]
  - **检验**：能证明「每次扩容翻倍」时 n 次 append 的总代价是 O(n)

- [ ] **L12 Hash Tables 哈希表** —— 建议 4 h
  - 核心：哈希函数、冲突处理（链地址法/开放寻址）、负载因子
  - 讲义：`90-原始PDF/15-122/lectures/12-hashing.pdf`（11 页）
  - 笔记：[[15-122-12-Hashing]]
  - **检验**：能解释为什么哈希表的期望 `O(1)` 依赖「哈希函数均匀」

- [ ] **L13 Hash Dictionaries 哈希字典** —— 建议 4 h
  - 核心：把哈希表包装成字典接口、键值对、迭代器
  - 讲义：`90-原始PDF/15-122/lectures/13-hdict.pdf`（27 页）
  - 笔记：[[15-122-13-Hash-Dictionaries]]
  - **检验**：能说清「字典」与「集合」的接口差异

- [ ] **L14 Genericity 泛型** —— 建议 6 h
  - 核心：`void*`、`\hastag`、函数指针三步法、C1、**五段内存模型**
  - 笔记：[[15-122-14-Genericity]]
  - 配套：`review-slides/14-fpointer.pdf`（25 页）
  - **检验**：能写出「泛型队列」的 `typedef void* elem;` 版本，并说明为什么 `void*` 不能解引用

- [ ] **L15 Binary Search Trees 二叉搜索树** —— 建议 6 h
  - 核心：有序不变式、查找 `O(h)`、插入、`is_ordered(T, lo, hi)` 的正确写法、退化
  - 笔记：[[15-122-15-Binary-Search-Trees]]
  - **检验**：能指出讲义 p11 那个「只比较父子」的 `is_ordered` 为什么是错的（给出反例）

- [ ] **L16 AVL Trees AVL 树** —— 建议 5 h
  - 核心：高度不变式、四种旋转情形、一次插入最多 1–2 次旋转、高度下界
  - 笔记：[[15-122-16-AVL-Trees]]
  - **检验**：能手画「插入后失衡」的四种情形（LL/LR/RL/RR）并说出各自用哪种旋转

### 阶段四：C 与机器（L17–L20）

> **从这一阶段起是标准 C，不是 C0。** 契约不再是语言的一部分，内存要自己管。

- [ ] **L17 Introduction to C C 入门** —— 建议 8 h
  - 核心：`#include`、宏与括号陷阱、`lib/contracts.h`、`xmalloc`/`free`、分离编译、**valgrind**
  - 笔记：[[15-122-17-Introduction-to-C]]
  - 配套：`gts/valgrind.pdf`（12 页）、`gts/style.pdf`（14 页）
  - **检验**：能解释 `#define INT_MIN -1 ^ 0x7FFFFFFF` 为什么会让 `INT_MIN/256` 算错

- [ ] **L18 C's Memory Model C 内存模型** —— 建议 8 h
  - 核心：五段布局（Stack/Heap/DATA/TEXT/OS）、数组与指针算术、**七类未定义行为**、栈变量地址
  - 笔记：[[15-122-18-C-Memory-Model]]
  - **检验**：能列出至少五类未定义行为，并各举一个 C 代码片段

- [ ] **L19 Types in C C 的类型** —— 建议 6 h
  - 核心：整数类型族、`<stdint.h>`、`size_t`、转换四情形、浮点陷阱、`union`/`enum`
  - 笔记：[[15-122-19-Types-in-C]]
  - **检验**：能算出 `int x = -15122` 转成 `(short)`、`(unsigned int)`、`(unsigned short)`、`(signed char)` 的结果

- [ ] **L20 The C0VM C0 虚拟机** —— 建议 8 h
  - 核心：栈机模型、字节码、常量池、函数调用五步、字节码验证
  - 笔记：[[15-122-20-Virtual-Machines]]
  - **检验**：能把 `(3+4)*5/2` 手工编译成字节码序列

### 阶段五：图与不变量（L21–L26）

- [ ] **L21 Representing Graphs 图的表示** —— 建议 5 h
  - 核心：无向图、邻接矩阵 vs 邻接表、`graph.h` 接口、复杂度对比
  - 笔记：[[15-122-21-Graph-Representation]]
  - **检验**：能说清 `neighbor_header` 这个包装结构为什么必需（提示：C 是值传递）

- [ ] **L22 Search in Graphs 图搜索** —— 建议 6 h
  - 核心：DFS（递归/显式栈）、BFS、**三条正确性不变式**、最短路径、隐式图
  - 笔记：[[15-122-22-Graph-Search]]
  - **检验**：能证明「栈空时若未找到目标，则不存在路径」

- [ ] **L23 Spanning Trees 生成树** —— 建议 6 h
  - 核心：树的六种等价刻画、边中心 vs 顶点中心、**Cycle Property**、Kruskal、Prim
  - 笔记：[[15-122-23-Spanning-Trees]]
  - **检验**：能完整写出 Cycle Property 的交换论证

- [ ] **L24 Union-Find 并查集** —— 建议 6 h
  - 核心：等价类、按高度合并、根存 `−h` 技巧、**「高度 h 的树至少 2^(h−1) 节点」的归纳证明**、路径压缩
  - 笔记：[[15-122-24-Union-Find]]
  - **检验**：能证明 v 个节点的并查集高度 ≤ log v，并推出 Kruskal 是 `O(e log e)`

- [ ] **L25 Priority Queues 优先队列** —— 建议 5 h
  - 核心：接口与有界版本、四种实现对比、最小堆的两条不变式、sift up/down、数组下标从 1
  - 笔记：[[15-122-25-Priority-Queues]]
  - **检验**：能解释 sift down 为什么必须与「较小的孩子」交换（给出反例）

- [ ] **L26 Restoring Invariants 恢复不变量** —— 建议 8 h
  - 核心：标准 C 重写堆、`elem[] data` 灵活数组、**部分不变式**、`grandparent_check`、完整正确性证明、heapsort
  - 笔记：[[15-122-26-Restoring-Invariants]]
  - **检验**：能说明「除 x 外都满足父子序」为什么不够强，并给出反例

## 三、复盘提醒

### 3.1 三个必须回头的节点

**节点一：学完 L08 后回头重读 L01。**
第 1 讲讲的是抽象方法论（契约、不变式、逐点推理），当时你没有任何具体算法可以套用。学完搜索、排序、库之后，你会发现 L01 的每个概念都在 L04–L08 里反复出现。**第二遍读 L01，收获远大于第一遍。**

**节点二：学完 L16 后做一次「数据结构总复盘」。**
L09–L16 讲了八种数据结构。它们的**接口**不同，但**论证方式**高度同构：

| 结构 | 不变式 | 修复操作 | 复杂度来源 |
|---|---|---|---|
| 无界数组 | 容量 ≥ 长度 | 扩容（倍增） | 摊还 |
| 哈希表 | 负载因子 ≤ 阈值 | 再哈希 | 期望值 |
| BST | 有序不变式 | 无（不修复） | 树高 h |
| AVL | 高度不变式 | 旋转 | 高度 ≤ 1.44 log n |
| 堆 | 有序 + 形状 | sift up/down | 完全树高度 |

**这张表就是 L26 的主题**——「先破坏、再局部修复」是所有动态数据结构的通用模式。

**节点三：学完 L20 后停下来，问自己「C0 与 C 到底差在哪」。**
L17–L20 四讲都在讲这个落差。最好的检验方式是：**把 L15 的 `bst.c0` 手工翻译成标准 C**，然后用 valgrind 跑，直到零泄漏。这个练习比读四遍讲义有用。

### 3.2 每讲之后的三个自问

1. **这一讲的核心不变式是什么？** 能不能用一句中文说清？
2. **如果去掉某个前置条件，会出什么错？** 能不能举一个具体的输入？
3. **这一讲的算法/结构，复杂度是怎么来的？** 能不能不看笔记推一遍？

如果三问里有两问答不上，**不要往下走**——后面的讲次会反复用到。

### 3.3 每周固定动作

- **周一**：读本周两讲的讲义 PDF（先不看笔记）。
- **周三**：读对应中文笔记，对照第 8 节的页码清单回查 PDF 的关键页。
- **周五**：做讲义末尾的习题，写完再看 sample solutions。**先写再看**——看懂答案和能写出来是两件事。
- **周日**：把本周的不变式抄到一张纸上，合上笔记复述一遍。

### 3.4 常见卡点与对策

| 卡点 | 出现位置 | 对策 |
|---|---|---|
| 循环不变式写不出来 | L01、L04、L06 | 先写「循环跑了 i 次之后，哪些量是什么」，再翻译成代码谓词 |
| 二分搜索的边界总写错 | L06 | 固定用一种写法（推荐半开区间 `[lo, hi)`），把不变式写死 |
| Big-O 的常数与低阶项分不清 | L05 | 记住定义：存在 c 和 n₀ 使 `f(n) ≤ c·g(n)` 对所有 `n ≥ n₀` |
| 旋转的四种情形记不住 | L16 | 只看「新节点在失衡节点的哪一侧的哪一侧」：外侧单旋、内侧双旋 |
| `void*` 为什么不能解引用 | L14 | 因为编译器不知道它指向多大的对象；解引用要先转成具体类型 |
| 标准 C 的段错误找不到 | L17–L19 | 用 `valgrind --leak-check=full`，先看第一个错误，不要看后面的连锁反应 |
| 指针算术的缩放搞不清 | L18 | `A + i` 的地址是 `A 的地址 + i * sizeof(*A)`，不是 `+ i` |
| 并查集的高度引理想不通 | L24 | 对 h 做归纳，注意「等高合并」是唯一让高度增加的情形 |
| sift down 与 sift up 混淆 | L25 | sift up 只跟父比；sift down 要在两个孩子里挑更优先的那个 |
| `grandparent_check` 为什么必需 | L26 | 亲手跑一遍反例：`[_, 0, 10, 1, 3, 15, 20, 30, 5, 6, 40]` 交换 4 与 2 |
