## 三、按主题分类

### 3.1 正确性方法论（贯穿全课）

| 讲次 | 关键工具 |
|---|---|
| L01 | 契约（`//@requires` / `//@ensures`）、循环不变式、断言、逐点推理、终止性论证 |
| L04 | 循环不变式的第一个实战（线性搜索） |
| L06 | 边界条件的精确表述（二分搜索的不变式最容易写错） |
| L26 | **部分不变式**（partial invariant）与「临时违反 → 局部修复」模式 |

### 3.2 复杂度分析

| 讲次 | 复杂度主题 |
|---|---|
| L05 | Big-O / Ω / Θ 的定义与运算规则 |
| L06 | `O(log n)`：二分搜索 |
| L07 | 期望 `O(n log n)` vs 最坏 `O(n²)`：快排 |
| L11 | **摊还分析**（amortized analysis）：无界数组扩容 |
| L16 | AVL 的 `O(log n)` 保证与高度下界 `F(h)` |
| L21 | 邻接矩阵 `O(v²)` vs 邻接表 `O(max(v,e))` |
| L24 | 并查集的 `O(e log e)` 与路径压缩的 `O(1 + A⁻¹(n))` |
| L25 | 优先队列四种实现的复杂度对比 |

### 3.3 数据结构

| 讲次 | 结构 | 核心不变式 |
|---|---|---|
| L09 | 栈、队列 | 容量与元素个数的关系 |
| L10 | 链表 | 链的完整性与无环性 |
| L11 | 无界数组 | 容量 ≥ 长度，扩容后仍满足 |
| L12–L13 | 哈希表 / 哈希字典 | 负载因子、链的完整性 |
| L15 | 二叉搜索树 | **有序不变式**（左 < 根 < 右） |
| L16 | AVL 树 | **高度不变式**（左右子树高度差 ≤ 1） |
| L24 | 并查集 | 等价类划分 + 高度追踪 |
| L25–L26 | 堆 | **有序不变式** + **形状不变式** |

| L20 | C0VM：栈机、字节码、常量池、字节码验证 | 把 C0 程序当数据看 |

### 3.5 图算法

## 五、使用建议

1. **读讲义前先看笔记的「第 3 节核心概念」与「第 4 节通俗理解」**，建立直觉后再读 PDF 的推导。
2. **第 5 节「原理与推导」对应讲义的主体部分**，页码在第 8 节列出，可对照阅读。
3. **第 6.1 节引用官方代码，第 6.2 节是自编示例**——后者标注「非官方」，只用于补足直觉，不能当官方材料引用。
4. **代码包需要解压**：`tar -xzf 90-原始PDF/15-122/code/15-bst.tgz`。包内通常有 `.c0` / `.c` 源文件、`.h` 接口、测试驱动。
5. **L17 起务必装好 valgrind**，并按 `gts/valgrind.pdf` 练习读报告。后五周的作业几乎都要求「零泄漏」。
