# 计算机科学学习笔记

一个中文的计算机科学学习知识库：16 个知识领域的原创笔记、可勾选的知识点清单，以及经实测核验的公开课程来源索引。

## 这个仓库是什么

- **16 个领域的地图**：数学基础、编程基础、数据结构与算法、计算机组成、操作系统、计算机网络、数据库、编译原理、软件工程、前端、后端、软件安全、DevOps、分布式系统、系统架构、计算机高级选修。
- **可勾选的知识点目录**：每个领域一份，条目粒度是「能独立讲清的一个概念」。
- **课程来源索引**：每门课附官方链接，链接状态由脚本实测（见 `scripts/verify_urls.py`）。
- **原创笔记**：已有 CMU 四门课的中文笔记，以及按知识点补齐的原创补课笔记。

## 这个仓库不包含什么

> 本仓库的教程与笔记为原创内容。引用的课程资料版权归各高校与作者所有，
> 仓库内**不包含**任何课程 PDF、课件、教材电子版。原始资料请访问 `sources/` 中登记的官方链接自行获取。

具体来说，以下内容**永远不在本仓库中**：

- 任何第三方讲义、作业说明、教材的 PDF 或扫描件
- 任何课程作业的答案、评分标准、学生提交
- 下载缓存、抓取中间产物、个人学习记录

这些内容位于本地私有目录（`local-materials/`、`personal-notes/`、`90-原始PDF/`、`_scout/`），已在 `.gitignore` 中排除。

## 目录结构

```
docs/                ← 唯一公开的内容源，也是站点构建范围
  00-知识地图.md
  01-学习路径.md
  10-数学基础/ … 160-计算机高级选修/    每域 00–04 号文件
  .vitepress/        ← 站点配置与自定义 Markdown 插件
sources/             ← 来源登记、许可判定规则、移除记录
exercises/           ← 原创练习
projects/            ← 实战项目

```

## 本地预览站点

```bash
npm install
npm run docs:dev        # 开发服务器
npm run docs:build      # 构建到 docs/.vitepress/dist/
npm run docs:preview    # 预览构建产物
```

构建范围固定为 `docs/`，私有目录不会进入产物。

## 从哪开始读

1. [`docs/00-知识地图.md`](docs/00-知识地图.md) —— 16 个领域各回答什么问题、互相依赖关系。
2. [`docs/01-学习路径.md`](docs/01-学习路径.md) —— 系统 / 全栈 / 算法三条主线。
3. 进入所选主线的第一个领域，读它的 `00-领域总览.md`。

## 来源与许可

- 每份被引用的外部材料都在 `sources/02-来源登记表.md` 有编号记录。
- 公开 / 私有的判定规则见 `sources/03-许可判定规则.md`。
- 被移除的来源记录在 `sources/05-移除记录.md`。
