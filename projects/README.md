# projects —— 实战项目区

> ✅ **这个目录会公开。** 项目代码 + 设计文档，是这份知识库最有价值的部分。

---

## 放什么

- 自己从零写的完整项目（含 README、构建脚本、测试）
- 跟着课程做的 lab，但**代码必须是自己写的**
- 造轮子：手写 Redis / HTTP 服务器 / 解释器 / 数据库
- 对开源项目的非平凡补丁（放在各自的子目录，注明上游仓库与提交）

## 不放什么

- 直接 fork 的仓库（用 git submodule 或只放链接）
- 课程原始框架代码（starter code 通常有许可限制）
- 别人的作业

---

## 每个项目必须有

```
projects/<项目名>/
├── README.md          ← 一句话说明 + 怎么跑 + 学到什么
├── SOURCE.md          ← 若基于课程/教程，写清出处与许可
├── src/ 或直接源码
├── tests/
└── .gitignore         ← 常见产物：target/ node_modules/ *.o
```

`README.md` 不是运行说明就够了，要回答：

1. 这个项目解决什么问题
2. 用到了哪些知识点（链接回 `docs/`）
3. 有哪些**已知缺陷**（诚实写，比吹牛有用）
4. 下一步会做什么

---

## 推荐按学习阶段推进

| 阶段 | 项目规模 | 对应领域 |
| --- | --- | --- |
| 入门 | 200–500 行 | 30 数据结构、40 组成 |
| 进阶 | 1000–3000 行 | 70 数据库、60 网络、50 操作系统 |
| 综合 | 5000+ 行 | 130 分布式、150 架构、120 后端 |
