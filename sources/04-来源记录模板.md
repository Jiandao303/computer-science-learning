# 来源记录模板

复制下面任意一个区块，填完贴进 `02-来源登记表.md`（或你自己领域的 `02-权威课程与资料.md`）。

---

## 单条记录（复制用）

```markdown
### [S-<编号>] <名称>

| 字段 | 内容 |
| --- | --- |
| 来源编号 | S-<编号> |
| 名称 | |
| 作者 / 机构 | |
| 年份 / 学期 | |
| 类型 | 课程主页 / 讲义 PDF / 教材 / 视频 / 开源代码 / 官方文档 / 论文 |
| 原始 URL | |
| 存档 URL | （可选：web.archive.org 快照） |
| 许可 | CC BY 4.0 / MIT / Apache-2.0 / 版权保留 / 未标注 |
| 可否再发布 | ✅ 可以 / ⚠ 仅链接 / ❌ 不可 |
| 本地存放 | `local-materials/<路径>` 或「无」 |
| 核验日期 | YYYY-MM-DD |
| 核验状态 | 200 可达 / 待核实 |
| 用途 | 阅读 / 翻译 / 引用 / 作业参考 |
| 备注 | |
```

---

## 字段填写约定

- **来源编号**：`S-` + 三位数字，全局唯一，不复用。删除的条目保留编号并标记「已移除」。
- **年份 / 学期**：写课程实际开课学期，如 `Fall 2026`。**不同学期的同名课程是不同来源**，不能合并。
- **原始 URL**：写课程主页，不写 PDF 直链。直链会随学期归档失效。
- **许可**：照抄原文，不要推断。找不到就写「未标注」。
- **可否再发布**：按 `03-许可判定规则.md` 判定。拿不准填「⚠ 仅链接」。
- **本地存放**：只登记相对 Vault 根的路径。私有区的路径不会被公开仓库收录。
- **核验日期**：用 `python scripts/verify_urls.py` 跑一遍后填当天日期。

```markdown
| YYYY-MM-DD | S-001 | 许可由「未标注」改为「CC BY 4.0」 | 课程页底部新增许可声明 |
```
