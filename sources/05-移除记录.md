## 处置原则

1. **只删 `docs/` 里的对应内容**，不动 `local-materials/` 的个人副本（那是私人阅读，不构成分发）。
2. **不 rewrite git 历史**。如果内容已进入历史，在 README 顶部加声明，并停止继续分发。
3. **同步更新 `02-来源登记表.md`**，把该来源标记为「已移除」，编号不复用。
4. 如果内容是你自己写的，只是引用了别人的材料，**改写引用部分**即可，不必整页删除。
