# 许可判定规则

> 这份文件回答一个问题：**某份资料能不能放进公开仓库？**
> 判不了的时候，默认答案永远是「不能」，放在 `local-materials/`。

---

## 一、三分区模型

| 分区 | 路径 | 能否公开 | 放什么 |
| --- | --- | --- | --- |
| **公开区** | `docs/`、`exercises/`、`projects/`、`sources/` | ✅ 可以 | 自己写的教程、练习、项目代码、来源登记 |
| **私有区** | `local-materials/`、`personal-notes/` | ❌ 默认不入库 | 第三方 PDF/课件/视频、个人学习记录 |
| **引用区** | `sources/` 里的链接 | ✅ 只放**链接** | 指向官方页面的 URL，不复制内容 |

关键区分：

- **"公开可下载" ≠ "可以再发布"**。课程讲义放在公网上，是给学生看的，不是授权你镜像转发。
- **"我改过了" ≠ "是我的"**。翻译、改写、截图标注都仍是衍生作品。
- **链接不侵权，内容才侵权**。所以 `docs/` 里可以写满指向官方 PDF 的链接，但不能把 PDF 放进去。

## 二、判定流程

对每一份想引入的资料，按顺序问：

```
1. 它是谁的作品？
   └─ 我自己写的 ────────────────→ 可进 docs/（仍需在 sources/ 登记）
   └─ 第三方 ──→ 继续

2. 许可证是什么？（查文件首页/Copyright 页/仓库 LICENSE）
   ├─ 明确标注 CC BY / CC BY-SA / MIT / Apache-2.0 / 公有领域
   │     └─→ 可再发布，但必须保留署名与许可声明 → docs/
   ├─ 明确标注"All rights reserved" / 无任何许可声明
   │     └─→ 只放链接，原文进 local-materials/ → 不入库
   └─ 标注"仅限选课学生" / 需要登录 / 需要学校账号
         └─→ **绝不入库**，连链接都需谨慎 → local-materials/

3. 是论文吗？
   └─ arXiv / 会议官方开放获取 ──→ 可链接；原文不复制
   └─ 出版社 PDF ────────────────→ 只链接 DOI

4. 是代码吗？
   └─ 看仓库 LICENSE 文件，不看 README 里的一句话
```

| Crafting Interpreters | 作者免费在线全文，代码 MIT | 可链接；代码引用需署名 |
| CLRS / CSAPP 等商业教材 | 版权保留 | **只写书名，不提供 PDF** |
| SEED Labs | 课程实验，页面公开 | 链接；实验解答不入库 |

> 上表是**当前判断**，不是永久结论。任何人发现某条判断有误，应直接修改本表并在 `04-来源记录模板.md` 里登记变更。

## 四、登记要求

任何进入 `docs/` 的第三方内容（引用超过 3 行、图片、代码片段），必须在对应页脚或 `sources/` 登记：

```
来源：<课程名>（<机构>，<年份>）
作者：<原作者>
许可：<许可证名 + 链接>
原文：<URL>
用途：<引用/改编/翻译>
```

缺任何一项，就不要放。

---

## 五、撤销机制

如果权利人要求移除：

1. 从 `docs/` 删除对应内容（这是唯一允许的"覆盖式删除"场景）。
2. 在 `sources/05-移除记录.md` 记一行：日期、内容、请求方、处置。
3. 如果内容已进入 git 历史，**不要 rewrite history**；在 README 顶部加声明并停止分发。
