# CMU 15-213 · 学习进度

> 勾选框用法：`- [x]` 表示「讲义读完 + 笔记读完 + 代码跑过 + 自我检查做完」四项都完成，不是只读了讲义。
> 入口页：[[20-CMU-15-213/00-课程总览|CMU 15-213 - 课程总览]]；逐讲索引：[[20-CMU-15-213/01-课程目录|CMU 15-213 - 课程目录]]。

## 一、总体安排

| 阶段 | 讲次 | 周次 | 建议总学时 | 主题 |
|---|---|---|---|---|
| **一、位与整数** | L01–L02 | 第 1–2 周 | 12 h | 课程全貌、补码、移位、字节序 |
| **二、机器级程序** | L03–L08 | 第 3–5 周 | 40 h | 汇编、控制流、过程、数据、链接、调试 |
| **三、存储层次与虚拟内存** | L09–L12 | 第 6–8 周 | 32 h | 局部性、cache 地址划分、页表、TLB |
| **四、动态内存分配** | L13–L14 | 第 9–10 周 | 20 h | 隐式 / 显式空闲链表、分离适配 |
| **五、优化、进程与 I/O** | L15–L18 | 第 11–14 周 | 30 h | 别名与 ILP、fork / execve、信号、RIO |

**合计约 134 小时**。按每周 10 小时算约 14 周，正好一个学期。

**时间不够时的取舍**（按性价比排序，从高到低保留）：

1. L10 缓存 + L15 优化 —— 面试与工程实践里最常被问的两块。
2. L11–L12 虚拟内存 —— 不理解这个，后面所有 OS 课都读不懂。
3. L13–L14 malloc —— 唯一能让你「亲手写出一个真实系统组件」的部分。
4. L16–L17 进程与信号 —— 写 shell、写服务器的基础。
5. L03–L06 机器级程序 —— 内容最多、最枯燥，但没有它 L10 之后全是空中楼阁。
6. L07 链接、L08 调试 —— 遇到问题再回查即可。
7. L02 位运算 —— 只在做 L1 Data Lab 时需要精细掌握。

## 二、18 讲逐讲 checklist

### 阶段一：位与整数（12 h）

- [ ] **L01 Course Overview 课程总览** —— 建议 3 h
  - 核心：课程地图、8 个 lab 的分工、评分构成、shark 机器与 Autolab
  - 笔记：[[15-213-01-Overview]]
  - 检验：能说出「L1 练位运算、L2 练读汇编、L3 练栈溢出、L4 练缓存、L5 练 malloc、L6 练 shell」这条主线
  - 讲义：`01-overview.pdf`（73 页）

- [ ] **L02 Bits, Bytes, and Integers 位、字节与整数** —— 建议 9 h
  - 核心：无符号 / 补码、符号扩展、截断、移位、溢出判断、小端序
  - 笔记：[[15-213-02-Bits-Bytes-and-Integers]]
  - 检验：不看笔记手算 `(unsigned)-1`、`INT_MIN == -INT_MIN`、`x << 1` 何时溢出
  - 讲义：`02-bits-bytes-ints.pdf`（76 页）

### 阶段二：机器级程序（40 h）

- [ ] **L03 Machine-Level Programming I: Basics** —— 建议 6 h
  - 核心：寄存器文件、`mov` 家族、地址模式 `D(Rb,Ri,S)`、`lea`
  - 笔记：[[15-213-03-Machine-Programming-I-Basics]]
  - 检验：能把 `a[i] = a[i] + 1` 翻译成三条指令并解释每条
  - 讲义：`03-machine.pdf`（73 页）

- [ ] **L04 Machine-Level Programming II: Control** —— 建议 6 h
  - 核心：条件码 ZF / SF / CF / OF、`cmp` / `test`、`jmp` 家族、`cmov`、循环、switch 跳转表
  - 笔记：[[15-213-04-Machine-Programming-II-Control]]
  - 检验：能解释为什么 `if (x > 0) y = 1;` 可能被编译成无分支代码
  - 讲义：`04-machine-beta.pdf`（66 页）
  - 配套练习：`machine-control.pdf`（10 页，含答案）

- [ ] **L05 Machine-Level Programming III: Procedures** —— 建议 8 h
  - 核心：栈帧、`call` / `ret`、6 个整型参数寄存器、栈上传参、被调用者保存寄存器、递归
  - 笔记：[[15-213-05-Machine-Programming-III-Procedures]]
  - 检验：能手画一个三层递归调用时的栈布局并标出每个 `%rsp` 的值
  - 讲义：`05-machine-gamma.pdf`（88 页，全课最长）
  - 配套练习：`machine-procedures.pdf`（3 页，含答案）

- [ ] **L06 Machine-Level Programming IV: Data** —— 建议 6 h
  - 核心：数组、指针算术、结构体布局与对齐、联合体、浮点寄存器（XMM）、`movss` / `movsd`
  - 笔记：[[15-213-06-Machine-Programming-IV-Data]]
  - 检验：能算出任意结构体的 `sizeof` 与每个字段的偏移
  - 讲义：`06-machine-delta.pdf`（71 页）
  - 配套练习：`machine-advanced.pdf`（7 页，含答案，含缓冲区溢出漏洞分析）

- [ ] **L07 Linking 链接** —— 建议 6 h
  - 核心：目标文件格式、符号表、静态链接、重定位、动态链接、位置无关代码（PIC）、GOT / PLT
  - 笔记：[[15-213-07-Linking]]
  - 检验：能解释 `undefined reference to 'foo'` 与 `multiple definition of 'x'` 各自的成因
  - 讲义：`07-linking.pdf`（51 页）

- [ ] **L08 Design and Debugging 设计与调试** —— 建议 8 h
  - 核心：gdb 断点与观察点、valgrind、代码风格、模块化设计、防御性编程
  - 笔记：[[15-213-08-Design-and-Debugging]]
  - 检验：能在 gdb 里用 `x/8gx $rsp` 读出栈上的返回地址
  - 讲义：`08-design-debugging.pdf`（71 页）

### 阶段三：存储层次与虚拟内存（32 h）

- [ ] **L09 Memory Hierarchy 存储器层次结构** —— 建议 8 h
  - 核心：SRAM / DRAM / 磁盘的速度与成本、局部性、存储层次、缓存的一般模型
  - 笔记：[[15-213-09-Memory-Hierarchy]]
  - 检验：能画出从寄存器到磁盘的完整层次并标出每层的延迟量级
  - 讲义：`09-memory-hierarchy.pdf`（74 页）

- [ ] **L10 Cache Memories 缓存存储器** —— 建议 12 h
  - 核心：S / E / B 三元组、地址划分为 tag | set | offset、直接映射与组相联、LRU、写策略、矩阵乘与分块
  - 笔记：[[15-213-10-Cache-Memories]]
  - 检验：给一个 `S=4, E=1, B=2` 的缓存和访问序列，能手算每一次命中 / 未命中；能手推 `kij` 与 `jki` 的 miss rate 为什么差 4 倍
  - 讲义：`10-cache-memories.pdf`（73 页）
  - 关联 lab：L4 Cache Lab（Part A 写模拟器，Part B 优化转置）

- [ ] **L11 Virtual Memory: Concepts 虚拟内存：概念** —— 建议 6 h
  - 核心：虚拟地址 vs 物理地址、MMU、页表、PTE、缺页、按需调页、保护位、TLB
  - 笔记：[[15-213-11-Virtual-Memory-Concepts]]
  - 检验：能默写缺页处理的 7 个步骤；能解释为什么页要大（4 KB）且必须全相联
  - 讲义：`11-vm-concepts.pdf`（43 页）

- [ ] **L12 Virtual Memory: Details 虚拟内存：细节** —— 建议 6 h
  - 核心：完整的两级翻译示例、多级页表、PTE 标志位、VIPT 缓存、内存映射文件、写时复制、fork 为什么便宜
  - 笔记：[[15-213-12-Virtual-Memory-Details]]
  - 检验：给一个 14 位 VA / 12 位 PA / 64 B 页的系统，能一步步算出 TLB 索引、TLB 标记、页表索引、cache 索引、cache 标记
  - 讲义：`12-vm-details.pdf`（41 页）

### 阶段四：动态内存分配（20 h）

- [ ] **L13 Dynamic Memory Allocation: Basic 动态内存分配：基础** —— 建议 10 h
  - 核心：堆与 `sbrk`、显式 vs 隐式分配器、碎片、吞吐量、块头与块脚、隐式空闲链表、首次适配、分割、四种合并情形
  - 笔记：[[15-213-13-Dynamic-Memory-Allocation-Basic]]
  - 检验：能手写 `mm_malloc` / `mm_free` / `coalesce`，并解释为什么需要边界标记
  - 讲义：`13-malloc-basic.pdf`（58 页）

- [ ] **L14 Dynamic Memory Allocation: Advanced 动态内存分配：进阶** —— 建议 10 h
  - 核心：显式空闲链表、LIFO / FIFO / 地址有序插入、分离适配、七类常见内存错误、valgrind
  - 笔记：[[15-213-14-Dynamic-Memory-Allocation-Advanced]]
  - 检验：能说出七类内存错误各举一例；能解释为什么分离适配能在「近常数时间」内完成分配
  - 讲义：`14-malloc-advanced.pdf`（43 页）
  - 关联 lab：L5 Malloc Lab

### 阶段五：优化、进程与 I/O（30 h）

- [ ] **L15 Code Optimization 代码优化** —— 建议 8 h
  - 核心：编译器能做什么 / 不能做什么、存储器别名、函数调用开销、内联、循环展开、指令级并行、分支预测
  - 笔记：[[15-213-15-Code-Optimization]]
  - 检验：能解释为什么 `for (i=0;i<n;i++) a[i] += b[i]` 在指针可能别名时无法被向量化；能算 CPE
  - 讲义：`15-optimization.pdf`（51 页）

- [ ] **L16 Processes and Multitasking 进程与多任务** —— 建议 8 h
  - 核心：进程抽象、逻辑控制流、私有地址空间、上下文切换、进程状态机、`fork` / `exit` / `wait` / `execve`
  - 笔记：[[15-213-16-Processes]]
  - 检验：能给出一段含 3 个 `fork` 的程序画出进程图并算出总共几个进程；能解释僵尸进程与孤儿进程的区别
  - 讲义：`16-processes.pdf`（68 页）

- [ ] **L17 Exceptional Control Flow 异常控制流** —— 建议 9 h
  - 核心：异常表、中断 / 陷阱 / 故障 / 中止、系统调用、信号、`signal` / `kill` / `sigprocmask` / `sigsuspend`、竞态
  - 笔记：[[15-213-17-Exceptional-Control-Flow]]
  - 检验：能解释为什么 `while (!pid) pause();` 有竞态，以及 `sigsuspend` 如何修好它
  - 讲义：`17-ecf.pdf`（66 页）
  - 关联 lab：L6 Tsh Lab

- [ ] **L18 System Level I/O 系统级 I/O** —— 建议 5 h
  - 核心：文件即字节序列、`open` / `close` / `read` / `write` / `stat`、短计数、RIO 包、标准 I/O 的缓冲、文件描述符表与打开文件表、`dup2` 重定向
  - 笔记：[[15-213-18-System-Level-IO]]
  - 检验：能解释 `ffiles1.c` 为什么输出 `a, a, b`；能说清 `dup2(4, 1)` 之后两次 `open` 的引用计数变化
  - 讲义：`18-system-io.pdf`（54 页）
  - 关联 lab：L6 Tsh Lab

## 三、Lab 与讲次的对应关系

| Lab | 需要先学完 | 建议投入 | 学不到会怎样 |
|---|---|---|---|
| **L0** CProgrammingLab | 15-122 的 C 基础 | 2–10 h | 后面全部 lab 都会卡在指针与 `malloc` 上 |
| **L1** Data Lab | L02 | 15 h | 位运算不熟，L3 的编码与 L10 的地址位划分会很吃力 |
| **L2** Bomb Lab | L03–L06 | 20 h | 读汇编的能力是后面所有 lab 的通用技能 |
| **L3** Attack Lab | L05、L06 | 15 h | 不理解栈帧就无法理解缓冲区溢出 |
| **L4** Cache Lab | L09、L10 | 25 h | 不写缓存模拟器，L10 的知识永远停留在纸面 |
| **L5** Malloc Lab | L11–L14 | 40 h | 这是全课最重的 lab，也是最能体现「系统编程」的一个 |
| **L6** Tsh Lab | L16–L18 | 30 h | 不写 shell，进程与信号就只是名词 |
| **L7** Proxy Lab | CSAPP 第 11 章（讲义未覆盖） | 25 h | 网络与并发需自学 |
| **L8** SFS Lab | CSAPP 第 12 章（讲义未覆盖） | 25 h | 文件系统需自学 |

> **Lab 顺序不能跳**：L1 → L2 → L3 是「位 → 汇编 → 栈」的递进；L4 → L5 是「缓存 → 堆布局」的递进。跳过 L2 直接做 L3，等于在不识字的情况下读诗。

公开可得性见 [[20-CMU-15-213/03-Lab实验笔记/00-Lab总览|15-213 Lab 总览]]；受限 lab 的替代学习路径见 [[20-CMU-15-213/03-Lab实验笔记/02-受限Lab说明|受限 Lab 说明]]。

## 四、每周节奏建议

| 时间 | 做什么 |
|---|---|
| **周一** | 读本周两讲的讲义 PDF（先通读，不求懂），标出看不懂的页 |
| **周二 / 周四** | 读对应中文笔记的第 5 节（原理与推导），把标出的页逐个啃下来 |
| **周三 / 周五** | 把第 6 节的代码示例全部编译运行一遍，用 `gcc -Og -S` 看汇编 |
| **周六** | 做第 11 节自我检查；做 lab 的当前阶段 |
| **周日** | 复盘：把本周的概念用自己的话写三句话总结；补 lab |

**一条经验**：这门课的讲义平均每页信息量很大（尤其 L05 的 88 页、L12 的 41 页），**不要试图一遍读懂**。第一遍只求「知道有这么个东西」，第二遍配合代码与 lab 才求「会用」，第三遍复习时才求「能讲给别人听」。

## 五、复盘提醒

### 5.1 三个必须回头看的节点

1. **学完 L10 之后** —— 回头重读 L09 的存储器层次图，此时你才会真正理解「为什么缓存要按块搬运而不是按字节」。
2. **学完 L12 之后** —— 回头重读 L10 的地址划分，你会发现 cache 的 tag | set | offset 与页表的 VPN | VPO 是同一套「切片」思想。
3. **学完 L14 之后** —— 回头重读 L11 的「堆在地址空间的哪里」，`sbrk` 与 `mm_malloc` 的关系会突然清晰。

### 5.2 五个最容易「以为自己懂了」的点

| 概念 | 假的懂 | 真的懂 |
|---|---|---|
| 缓存命中率 | 会套公式 | 能解释为什么 `jki` 顺序的 miss rate 是 `kij` 的 4 倍，并能手算一个具体例子 |
| 虚拟内存 | 会说「有个页表」 | 能画出 VA → TLB → 页表 → PA → cache 的完整数据通路，并说出每一步失败时的后果 |
| malloc | 会调 `malloc` / `free` | 能手写 `coalesce` 的四种情形，并解释为什么释放后还要写块脚 |
| fork | 会说「复制进程」 | 能解释写时复制让 `fork` 变便宜，以及为什么子进程里 `printf` 的缓冲区内容会重复出现 |
| 信号 | 会写 `signal(SIGINT, handler)` | 能解释为什么 handler 里只能调 `write` 不能调 `printf`，以及 `sigsuspend` 解决的是什么竞态 |

### 5.3 复习节奏

| 时点 | 复习内容 |
|---|---|
| 学完 L06 后 | L02–L06：位 → 汇编 → 控制 → 过程 → 数据，一条线串一遍 |
| 学完 L12 后 | L09–L12：层次 → 缓存 → 页表 → 多级页表，画出完整的数据通路图 |
| 学完 L14 后 | L11–L14：地址空间 → 页表 → 堆 → 分配器，理解「谁在管内存」 |
| 学完 L18 后 | L16–L18：进程 → 异常 / 信号 → 系统调用 → 文件，画出「一次 `read` 从用户态到磁盘」的路径 |
| 全课结束后 | 用一张 A4 纸默画：地址空间布局 + 缓存层次 + 一次函数调用的栈变化 + 一次系统调用的路径 |
