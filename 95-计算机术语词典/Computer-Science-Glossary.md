# 计算机专业术语词典

本词典收录四门 CMU 课程中反复出现的中英文术语，用于统一全库翻译口径。所有中文笔记中的术语译名以此表为准。

**使用方式**：在笔记中首次出现英文术语时写成「English（中文）」，例如 `Loop Invariant（循环不变量）`。若发现词典缺词，请在此表补一行，不要各篇笔记自创译名。

**「首次出现课程」列**表示该术语在本知识库中最早系统讲解的课程，不代表它只属于该课程。

## 术语统一规则（写作时强制）

1. **一个英文术语只对应一个中文译名**，反向不要求唯一（例如 Heap 在数据结构语境译「堆」，在内存管理语境也译「堆区」，须加限定词）。
2. 首次出现写成「English（中文）」，之后可只用中文。
3. 专有名词保持原文：C0、C、Java、SQL、x86-64、Valgrind、GDB、BusTub、PostgreSQL、Raft。
4. 不译缩写：ACID、CAP、MVCC、WAL、2PL、RPC、DSL、TLB、ISA。
5. 易混淆词必须在笔记第 7 节做对比表，例如：
   - Precondition vs Postcondition
   - Loop Invariant vs Assertion
   - C0 vs C
   - Stack（数据结构）vs Stack（调用栈）
   - Heap（数据结构）vs Heap（内存堆区）
   - Latch vs Lock（15-445）
   - Cache（硬件缓存）vs Buffer Pool（数据库缓冲池）
